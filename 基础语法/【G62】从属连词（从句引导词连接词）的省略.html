【G62】从属连词（从句引导词/连接词）的省略

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G62 是「基础语法」系列第62课，由陈老师主讲。本节课是句子部分的方法论专题课（续），紧接 G61「连接词个数不等于V-1是怎么回事？」，专门讲解 G61 中预告的第四种原因——省略。

在此之前，同学们已经学习了 G61 提出的四种连接词个数 ≠ V-1 的原因：①第二层并列、②找错谓语（AABB型动词）、③找错连接词（that的多重身份）、④省略。本节课聚焦第四种原因，深入探究从句引导词省略的三种常见情况和背后的本质原因。

本节课的核心目标：掌握从句引导词省略的三种常见情况（宾从第一个that、定从中做宾语的关系代词、先行词为the way的定从），并理解省略的本质原因——"不要引导词已经很清晰了"。
前置知识要求：
本节课建立在 G40「五大基本句型」、G43「从句/复合句1.0」、G51「省略」、G60「长难句3」、G61「连接词个数≠V-1」的基础上。需要熟练掌握宾语从句、定语从句、关系代词、非谓语动词等知识。

2. 核心问题：引导词省略的本质

老师首先指出一个普遍现象——很多同学被告知引导词省略是"固定搭配"，但这并不是本质原因。老师要探究的是：为什么引导词可以省略？

核心逻辑：
- 引导词的作用：让句子更加清晰明了（就像运动会举牌子的人）
- 既然引导词让句子更清晰，为什么还要省略？
- 答案：不是想让句子不清晰，而是不要引导词已经很清晰了
- 类比：班上有个姚明，不用举牌子也能一眼认出来

3. 省略的三种常见情况

老师列举了三种最常见的引导词省略情况，每种情况都有严格的条件限制：

情况一：宾语从句的第一个 that 可以省略

条件 说明
条件1 必须是宾语从句（宾从）
条件2 必须是第一个 that（不是第二个及以后的 that）
条件3 必须是 that（其他连接词不适用）
可省略：I think (that) you are a pig.
→ I = 主语；think = 谓语（及物动词）→ 后面缺宾语 → 宾从 → 第一个 that → 可省略 ✓
不可省略：I think that you are a pig and (that) you are ugly.
→ 第二个 that（and 后面的 that）→ 被 and 隔开了 → 不能省略 ✗
核心辨析——第一个 that 可省略，第二个 that 不可省略：
- 第一个 that：紧跟在谓语 think 后面 → 位置近 → 很清楚是宾从 → 可省略
- 第二个 that：被 and 隔开了 → 位置远 → 需要举牌子标识 → 不可省略
- 类比：紧跟在姚明后面的，大家都知道是姚明一伙的；隔远了，鬼知道你是谁

4. 情况二：定从中做宾语的关系代词可以省略

条件 说明
条件1 必须是定语从句（定从）
条件2 关系代词（that/which/whom）在从句中做宾语
可省略：The book (that) I bought yesterday is good.
→ 主句：The book is good（完整 ✓）→ 定从 ✓
→ 从句：I bought yesterday（缺宾语）→ that 做 bought 的宾语 ✓
→ 名词 book 后面紧跟 that → 很清楚 that 修饰 book → 可省略 ✓
核心辨析——为什么定从中做宾语的关系代词可以省略：
- 名词（the book）后面接从句 → 很明显是在修饰这个名词 → 引导词 that 可省略
- 类比：姚明那么高，不用举牌子也能认出来
- 本质：名词后面接从句已经很清晰了，不需要引导词来标识

5. 情况三：先行词为 the way 的定从中引导词可以省略

条件 说明
条件1 必须是定语从句（定从）
条件2 先行词必须是 the way
条件3 从句必须完整（不缺主语/宾语等成分）
条件4 引导词可以用 that / in which / 省略（三种选择）
三种等价表达：
① I like the way (that) you lie.
② I like the way (in which) you lie.
③ I like the way you lie.（省略引导词）
→ 主句：I like the way（完整 ✓）→ 定从 ✓
→ 从句：you lie（完整 ✓，lie 是不及物动词，不缺宾语）
→ 先行词 the way → 从句完整 → 引导词可用 that / in which / 省略
核心辨析——为什么 the way 的引导词可以用 that：
- 按理说 the way（方式）应该用 how 引导 → 但定语从句中没有 how 这个引导词
- 所以英语找了 that 或 in which 来替代
- 同样，省略也是可以的，因为名词 the way 后面紧跟从句 → 已经很清晰了

6. 补充情况：口语中的 other 省略

老师提到，除了上述三种常见情况，口语中还有其他省略现象：

I like the reason (why) you cried.
→ 口语中 the reason 后面的 why 也可以省略（严格语法中应该用 why）
→ 本质原因同上：名词 reason 后面紧跟从句 → 已经很清晰了
核心逻辑：口语中有些省略是习惯用法，但根本原因仍然是"不要引导词已经很清晰了"。老师强调，最常见的还是前两种情况（宾从第一个that / 定从中做宾语的关系代词）。

7. 省略的本质原因（核心颠覆点）

老师揭示了引导词省略的根本原因，这是一个颠覆很多同学认知的重要概念：

引导词省略的本质原因

引导词的作用是让句子更加清晰明了
如果不要引导词，句子已经很清晰了
→ 就可以省略引导词

反之，如果引导词离它修饰的名词/谓语太远了
→ 就需要保留引导词来"举牌子"标识
→ 就不能省略
核心口诀：
- 引导词 = 运动会举牌子的人 → 让句子更清晰
- 省略 ≠ 固定搭配 → 省略是因为"已经很清晰了"
- 位置近 → 清晰 → 可省略（如宾从第一个that紧跟谓语）
- 位置远 → 不清晰 → 不可省略（如第二个that被and隔开）
- 名词后紧跟从句 → 清晰 → 可省略（如定从中that做宾语）
- 不是想让句子不清晰，而是不要引导词已经很清晰了

8. 三种省略情况完整总结表

情况 从句类型 引导词 条件 例句
情况一 宾语从句 that（第一个） ①是宾从 ②是第一个that ③是that I think (that) you are a pig.
情况二 定语从句 that/which/whom（做宾语） ①是定从 ②关系代词在从句中做宾语 The book (that) I bought yesterday is good.
情况三 定语从句 that / in which / 省略 ①是定从 ②先行词是the way ③从句完整 I like the way (that/in which) you lie.

9. 可省略 vs 不可省略 对照表

例句 能否省略 原因
I think that you are a pig. ✅ 可省略 宾从 + 第一个that + 紧跟谓语think → 很清晰
I think that you are a pig and that you are ugly. ❌ 不可省略 第二个that被and隔开了 → 位置远 → 需要举牌子
The book that I bought yesterday is good. ✅ 可省略 定从 + that做宾语 + 紧跟名词book → 很清晰
I like the way that/in which you lie. ✅ 可省略 定从 + 先行词the way + 从句完整 → 很清晰
I like the reason why you cried. ✅ 可省略（口语中） 名词reason后紧跟从句 → 很清晰 → 口语中可省略

10. 核心知识点总结

知识点一：引导词省略的三种情况

判断维度 情况一（宾从） 情况二（定从-宾语） 情况三（定从-the way）
从句类型 宾语从句 定语从句 定语从句
引导词 that（第一个） that/which/whom（做宾语） that / in which / 省略
核心条件 ①宾从 ②第一个 ③就是that ①定从 ②关系代词做宾语 ①定从 ②先行词the way ③从句完整
典型例句 I think (that) you are right. The book (that) I bought... I like the way (that) you...

知识点二：省略的本质原因

判断维度 说明
引导词的作用 让句子更加清晰明了（就像运动会举牌子的人）
可省略的条件 不要引导词，句子已经很清晰了 → 可以省略
不可省略的条件 引导词离它修饰的对象太远了 → 需要保留来"举牌子"标识
位置近 → 清晰 → 可省略 宾从第一个that紧跟谓语 / 定从中that紧跟名词
位置远 → 不清晰 → 不可省略 第二个that被and隔开 → 需要保留
不是固定搭配 省略有本质原因，不是死记硬背的固定搭配

知识点三：姚明类比法

类比 语法对应
姚明很高，不用举牌子也能认出来 位置很近，引导词的作用已经很清晰了 → 可省略
隔远了，鬼知道你是谁，需要举牌子 位置远了，需要引导词来标识 → 不可省略
全班都是光头，也不用举牌子 语境太明显了，不需要引导词也能理解 → 可省略

11. 核心判断逻辑总结

G62 核心方法总结

第一步：看到 that / which / why 等引导词 → 想想能不能省略
↓
第二步：判断属于哪种情况
 情况一：宾从 + 第一个 that → 可省略
 情况二：定从 + 关系代词做宾语 → 可省略
 情况三：定从 + 先行词 the way → 可省略

第三步：判断位置远近
 位置近（紧跟谓语/名词）→ 清晰 → 可省略
 位置远（被 and 等隔开）→ 不清晰 → 不可省略
↓
第四步：记住本质原因
 不是固定搭配！不是想让句子不清晰！
 而是"不要引导词已经很清晰了"→ 所以可以省略
核心口诀：
- 引导词 = 举牌子的人 → 让句子更清晰
- 省略的本质：不要引导词已经很清晰了
- 位置近 → 可省略（宾从第一个that / 定从宾语关系代词 / the way）
- 位置远 → 不可省略（第二个that被and隔开）
- 不是固定搭配！有本质原因！
- 姚明类比：高个子不用举牌子

🎓 学习建议总结

  1. 牢记省略的三种情况：①宾从第一个that（三个条件：宾从+第一个+that）②定从中做宾语的关系代词 ③先行词为the way的定从（that/in which/省略三种选择）。
  2. 牢记省略的本质原因：不是固定搭配！不是想让句子不清晰！而是"不要引导词已经很清晰了"→ 所以可以省略。这是老师研究出来的本质，语法书上不说、很多老师也不知道。
  3. 牢记位置远近判断法：位置近（紧跟谓语/名词）→ 清晰 → 可省略；位置远（被and等隔开）→ 不清晰 → 不可省略。第二个that被and隔开 → 不可省略。
  4. 牢记姚明类比法：姚明很高，不用举牌子也能认出来 → 位置近可省略；隔远了，鬼知道你是谁 → 位置远不可省略。这个类比帮助理解省略的本质。
  5. 牢记 the way 的特殊性：先行词是 the way 时，引导词可以用 that / in which / 省略。因为 way（方式）按理应用 how 引导，但定从中没有 how，所以找了 that/in which 替代。
  6. 牢记口语补充：口语中 the reason 后面的 why 也可以省略（如 I like the reason you cried），本质原因同样是"名词后紧跟从句已经很清晰了"。
