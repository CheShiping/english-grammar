【G70】真正大招来了：一张图归纳所有英语句子

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G70 是「基础语法」系列第70课，由陈老师主讲。本节课是整个语法系列的总纲课/收官课，紧接 G69「强调句」。老师在前69节课中讲了大量重要且深刻的语法知识，但内容比较散乱，本节课的目标是将前面所有知识点串联起来，用一个万能公式——简单陈述句模型，将几乎所有的英语句子囊括进去。

本节课重点讲解：① 简单陈述句模型的完整结构、② 名词的六种形式（含it做形式主语）、③ 谓语的三种构成方式（助动词/实系动词/系动词）、④ 五大基本句型（SV/SVO/SVOC/SVIO DO/SVT）的推导、⑤ 句子复杂化的三种方法（从句/并列/分裂）、⑥ 模型的三种例外（祈使句/倒装句/强调句）。

本节课的核心目标：掌握简单陈述句的万能模型——(状语) + S + (后置定语/状语/同位语/插入语) + V + ...，理解所有英语句子都是在这个简单模型基础上，通过"从句""并列""分裂"三种方法复杂化而来。
前置知识要求：
本节课是前面69节课的总和，需要熟练掌握前面所有知识点：五大基本句型、动词分类、从句、非谓语、后置定语、同位语、倒装、强调句等。

2. 简单陈述句万能模型

老师提出了本节课最核心的公式——简单陈述句模型：

(状语) + S + (后置定语/状语/同位语/插入语) + V + ...
核心口诀：
- 句子开头不一定是主语，前面可以有状语（In the morning / Yesterday / When I was young...）
- 主语后面一定是谓语，但主谓之间可能有"障碍物"（后置定语/状语/同位语/插入语）
- 谓语后面是各种成分（宾语/表语/补语等），后面还可以继续加定语/状语/同位语
- 状语是最强大的，到处都可以放

3. 主语（S）的六种形式

老师详细讲解了主语（名词性成分）的六种形式，分为两大类：

第一类：名词性成分（前面可加后置定语缩小范围）

序号 名称 说明 特点
1 名词短语 普通名词+定语 很笼统，后面可加后置定语
2 DTS 代词/限定词/数词 很笼统，后面可加后置定语
3 Shots （名词性缩略形式） 很笼统，后面可加后置定语

第二类：长形式（可能头重脚轻，前面用it做形式主语）

序号 名称 抽象形式 特点
4 不定式 to do 太长，前面可能用it做形式主语
5 动名词 doing 太长，前面可能用it做形式主语
6 从句 引导词 + 句子 太长，前面可能用it做形式主语
核心辨析——it的两种身份：
- it做人称代词（如 It is good / It is sunny）→ it就是主语本身
- it做形式主语（如 It is good to learn English）→ it代替后面的不定式/动名词/从句
- 判断方法：看到 it 开头 + to do / doing / that 从句 → 很可能是形式主语

4. 主谓之间的"障碍物"

老师强调，主谓之间不一定直接跟着谓语，可能隔着各种"障碍物"：

障碍物类型 概率（从高到低） 例句
谓语 最高 I finally found you.
后置定语 高 The boy sitting there is my brother.
状语 中 I really like you.
同位语 低 I, a seventeen-year-old boy, am your friend.
插入语 最低（到处可插入） The movie, I think, is great.
核心口诀：
- 看到句子不要慌，按概率依次判断主谓之间是什么
- 概率排序：谓语 > 后置定语 > 状语 > 同位语 > 插入语
- 状语是最强大的，到处都可以放（I can hardly speak English）

5. 谓语的三种构成方式

老师将谓语部分拆解为三种构成方式，这是本节课最精彩的部分：

谓语构成 说明 后面接什么 能否单独构成谓语
助动词 起辅助作用，不能单独构成谓语 doing / done / 动词原形 ❌ 必须加实系动词或系动词
实系动词 表具体动作 可单独使用 / 也可加宾语 ✅ 可以单独构成谓语
系动词 不表具体动作，表状态 表语（名词/形容词/副词/介词短语） ✅ 可以单独构成谓语
核心口诀——助动词的分类：
- be动词（am/is/are/was/were）→ 后面接 doing 或 done
- 情态动词（can/could/may/might...）→ 后面接动词原形
- 狭义助动词（do/does/did）→ 后面接动词原形
- 完成助动词（have/has/had）→ 后面接过去分词（done）
核心逻辑：谓语的开头可能是助动词/实系动词/系动词，但谓语的结尾一定会落脚到实系动词或系动词身上。助动词可以层层叠加（最多三个），但最终还是要落脚到实系动词或系动词。

6. 五大基本句型的推导

老师从实系动词的分类（vi/vt）出发，推导出五大基本句型：

句型一：SV（主谓）

→ S + vi（不及物动词）→ 不接宾语 → SV结构
→ 后面可加状语（修饰动词）或补语
→ 例：I got up. / He runs every day.

句型二：SVO（主谓宾）

→ S + vi + 介词 + O → 构成SVO结构
→ 或 S + vt1（接一个宾语）→ SVO结构
→ 后面可加定语（O是名词）/ 状语 / 同位语
→ 例：I play basketball. / She likes reading.

句型三：SVOC（主谓宾宾补）

→ S + vt1 + O + C（宾补）→ SVOC结构
→ 宾补：名词/形容词/介词/to do/doing/done
→ 例：I think you beautiful.（我认为你很漂亮）
→ 宾补后面也可加定语/状语

句型四：SVitOC（形式宾语结构）

→ S + V + it（形式宾语）+ O + C + 真正的O（to do/doing/that从句）
→ 当真正的宾语太长（头重脚轻）时，用it做形式宾语
→ 例：We all think it important to learn English well.
→ 真宾语：to learn English well（不定式做真正的宾语）
核心辨析——形式宾语it vs 形式主语it：
- 形式主语：It is good to learn English.（it代替后面的to do做主语）
- 形式宾语：We think it important to learn English.（it代替后面的to do做宾语）
- 共同点：都是it代替后面太长的成分，避免头重脚轻

句型五：SVIO DO（主谓间宾直宾）

→ S + vt2（接两个宾语）+ IO（间宾）+ DO（直宾）→ SVIO DO结构
→ 可变序：S + vt2 + DO + to/for + IO
→ 例：She told me a story. → She told a story to me.
→ IO和DO都是宾语（名词性），后面可加定语/状语/同位语

句型六：SVT（主系表）

→ S + 系动词 + P（表语）→ SVT结构
→ 表语：名词/形容词/副词（小副词如in/out）/ 介词短语
→ 例：He is a student. / She is beautiful. / He is at home.
→ there be句型 = SVT的倒装演化形式
核心辨析——表语 vs 宾语/补语：
- 表语（P）：系动词后面，描述主语的状态 → 名词/形容词/副词/介词短语
- 宾语（O）：及物动词后面，接受动作 → 名词性成分
- 补语（C）：宾语后面，补充说明宾语 → 名词/形容词/介词/to do/doing/done
- 表语的范围比宾语/补语更广，因为系动词不表具体动作，表状态

7. 句子复杂化的三种方法

老师指出，所有复杂的英语句子，都是在简单陈述句模型的基础上，通过三种方法复杂化而来的：

方法 核心逻辑 说明
① 从句 用一个句子来充当某个成分 状语用句子→状语从句；主语用句子→主语从句；定语用句子→定语从句；宾语用句子→宾语从句；表语用句子→表语从句；同位语用句子→同位语从句；宾补用句子→宾补从句；间宾/直宾用句子→间宾从句/直宾从句
② 并列 像病毒复制一样，用and连接相同结构 主语and主语 / 谓语and谓语 / 状语and状语 / 句子and句子（并列句）→ 无穷无尽
③ 分裂（嵌套） 环环相扣，像细胞分裂一样 主语里的名词可以再分（有主谓）；谓语里的动词可以再分；状语从句里也有主谓；定语从句里也有主谓 → 子子孙孙无穷尽也
核心口诀：
- 从句 = 用一个句子充当某个成分（状语从句/主语从句/定语从句/宾语从句/表语从句/同位语从句/宾补从句/间宾从句/直宾从句）
- 并列 = 用and连接相同结构（主语and主语/谓语and谓语/状语and状语/句子and句子）
- 分裂 = 环环相扣，每个成分里面可以再分（定语从句里有主谓，状语从句里也有主谓）
- 所有复杂句 = 简单句 + 从句/并列/分裂

8. 模型的三种例外

老师指出简单陈述句模型有三种例外情况，不满足这个模型：

例外类型 核心特征 说明 例句
① 祈使句 省略主语和助动词，动词原形开头 本质上是省略了主语和助动词，仍然满足模型，但看起来不满足 Do it. / Be careful.
② 倒装句 谓语跑到主语前面 包括完全倒装和 partial倒装（疑问句也是部分倒装） Can you speak English? / Here comes the bus.
③ 强调句 在完整简单句基础上加了 It is/was...that 多了 It is/was...that 三个词，不满足简单模型 It was in the classroom that she told me.
核心逻辑：祈使句本质上是省略（省略主语和助动词），倒装句是语序颠倒，强调句是加了额外成分（It is/was...that）。这三种是简单陈述句模型的"例外"，但理解了本质后也不难。

11. 核心知识点总结

知识点一：简单陈述句万能模型

判断维度 说明
模型公式 (状语) + S + (后置定语/状语/同位语/插入语) + V + ...
开头 不一定是主语，前面可以有状语（In the morning / Yesterday / When I was young）
主谓之间 可能有障碍物：后置定语/状语/同位语/插入语（概率从高到低）
谓语结尾 无论前面加多少助动词，最终一定落脚到实系动词或系动词

知识点二：名词的六种形式

分类 形式 特点
第一类（笼统） 名词短语 / DTS / Shots 前面可加后置定语缩小范围
第二类（太长） 不定式(to do) / 动名词(doing) / 从句(引导词+句子) 可能头重脚轻 → 前面用it做形式主语/宾语

知识点三：谓语的三种构成

构成方式 能否单独构成谓语 助动词子类及后接形式
助动词 ❌ 不能 be→doing/done；情态→原形；do/does/did→原形；have/has/had→done
实系动词 ✅ 能 vi→SV；vi+介词→SVO；vt1→SVO/SVOC
系动词 ✅ 能 → SVT（主系表），含there be倒装

知识点四：句子复杂化的三种方法

方法 核心逻辑 结果
从句 用一个句子充当某个成分 状语从句/主语从句/定语从句/宾语从句/表语从句/同位语从句/宾补从句/间宾从句/直宾从句
并列 用and连接相同结构 主语and主语/谓语and谓语/状语and状语/句子and句子
分裂 环环相扣，每个成分可以再分 定语从句里有主谓，状语从句里也有主谓→子子孙孙无穷尽

知识点五：模型的三种例外

例外 本质 特征
祈使句 省略主语和助动词 动词原形开头（Do it. / Be careful.）
倒装句 谓语跑到主语前面 含完全倒装和partial倒装（疑问句也是部分倒装）
强调句 在完整简单句上加 It is/was...that 多了三个词，不满足简单模型

12. 核心判断逻辑总结

G70 核心方法总结

第一步：看到句子 → 先看开头有没有状语（In the morning / Yesterday...）
↓
第二步：找到主语 S（六种形式：名词短语/DTS/Shots/to do/doing/从句）
↓
第三步：判断主谓之间的"障碍物"（概率排序：谓语>后置定语>状语>同位语>插入语）
↓
第四步：找到谓语 V（三种构成：助动词→实系动词/系动词）
↓
第五步：判断句型（SV/SVO/SVOC/SVitOC/SVIO DO/SVT）
↓
第六步：看句子复杂化方式（从句/并列/分裂）
↓
第七步：检查是否是例外（祈使句/倒装句/强调句）
核心口诀：
- 简单陈述句模型：(状语) + S + (障碍物) + V + ...
- 名词六种：名词短语/DTS/Shots/to do/doing/从句
- 主谓之间障碍物：谓语>后置定语>状语>同位语>插入语
- 谓语三种构成：助动词(不能单独)/实系动词(可单独)/系动词(可单独)
- 助动词四类：be→doing/done；情态→原形；do→原形；have→done
- 五大句型：SV/SVO/SVOC/SVitOC/SVIO DO/SVT(含there be)
- 复杂化三方法：从句/并列/分裂
- 三种例外：祈使句/倒装句/强调句
- 谓语结尾一定落脚到实系动词或系动词

🎓 学习建议总结

  1. 牢记简单陈述句万能模型：(状语) + S + (后置定语/状语/同位语/插入语) + V + ...。这是本节课最重要的方法论，掌握了这个模型就掌握了所有英语句子的内核。
  2. 牢记名词的六种形式：名词短语/DTS/Shots（可加后置定语）和 to do/doing/从句（可能用it做形式主语/宾语）。
  3. 牢记主谓之间的障碍物概率排序：谓语 > 后置定语 > 状语 > 同位语 > 插入语。看到句子不要慌，按概率依次判断。
  4. 牢记谓语的三种构成：助动词（不能单独）/ 实系动词（可单独，表具体动作）/ 系动词（可单独，不表具体动作）。谓语结尾一定落脚到实系动词或系动词。
  5. 牢记助动词的四类及后接形式：be→doing/done；情态→原形；do/does/did→原形；have/has/had→done。
  6. 牢记五大句型及其扩展：SV/SVO/SVOC/SVitOC/SVIO DO/SVT（含there be）。每个句型后面都可以加定语/状语/同位语。
  7. 牢记复杂化三方法：从句（用一个句子充当成分）/ 并列（用and连接相同结构）/ 分裂（环环相扣）。所有复杂句 = 简单句 + 从句/并列/分裂。
  8. 牢记三种例外：祈使句（省略主语和助动词）/ 倒装句（谓语跑到主语前面）/ 强调句（It is/was...that...）。
  9. 综合应用建议：拿到任何长难句，先用简单陈述句模型定位主谓，再判断句型，再分析复杂化方式（从句/并列/分裂），层层拆解，万无一失。
