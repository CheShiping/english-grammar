【G19】非谓语之上帝视角（抽象思维）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G19 是「基础语法」系列第19课，由陈老师主讲。本节课是动词部分的思维突破课，专门讲解非谓语动词的基础概念，并引入一种全新的思维方式——抽象思维。

非谓语动词（to do / doing / done）在整个英语学习阶段都是非常非常困难的，很多同学遇到非谓语时脑袋完全乱掉。本节课从基础入手，即便只听基础部分，对非谓语的认识也会发生翻天覆地的变化，思维方式会完全改变。

本节课的核心目标：用"抽象思维"（牛顿式思维）透过表面现象看本质，秒判非谓语动词的三种形式（to do / doing / done），并学会区分谓语与非谓语。
前置知识要求：
本节课建立在 G12「动词分类」、G15「谓语的构成」的基础上。需要理解谓语动词和非谓语动词的基本区别，以及动词的过去式和过去分词变化规则。

2. 核心思想：抽象思维（上帝视角）

在理解非谓语之前，老师先普及一种思维方式——抽象思维。这是本节课最重要的方法论基础。

什么是抽象思维？

抽象思维就是透过表面的现象，看到内在的东西。老师用两个经典例子来说明：

例子一：直角三角形

✅ 表面上看，各种三角形朝各个方向，样子各不相同
✅ 但它们的共同特点是：都是三角形，且有一个角是直角
✅ 所以抽象出来就是：直角三角形（RT triangle）

例子二：牛顿与苹果

✅ 一般人看到苹果砸头 → "好倒霉啊"
✅ 牛顿看到苹果砸头 → 发现了万有引力定律
核心区别：
- 一般人的思维 = 停留在表面现象（下雨了、打雷了、树叶掉了）
- 牛顿的思维 = 透过现象看本质（万有引力）
- 这就是抽象思维：不被表面现象迷惑，看到内在规律
- 学非谓语也要用这种"牛顿式思维"

3. 非谓语的三种形式：to do / doing / done

非谓语动词只有三种形式，不要被表面现象迷惑，用抽象思维秒判断：

第一种：to do（to + 动词原形）

✅ 只要看到前面两个字母是 to → 就是 to do 形式 → 非谓语
✅ 例如：to be → 抽象成 to do（be 是动词原形）

第二种：doing（以 -ing 结尾）

✅ 只要第一个词冲起来就是 -ing → 就是 doing 形式 → 非谓语
✅ 例如：having been reported → 不管后面多复杂，看前面是 -ing → 非谓语
✅ 例如：being → 以 -ing 结尾 → 非谓语

第三种：done（过去分词形式）

✅ 过去分词形式（done）→ 非谓语
✅ 例如：gone（go 的过去分词）→ 非谓语
✅ 例如：drunk（drink 的过去分词）→ 非谓语
✅ 例如：written（write 的过去分词）→ 非谓语
核心方法：不要管后面跟了一堆什么 been stolen、having been reported，只看前面！to 开头 → to do；-ing 结尾 → doing；过去分词 → done。一秒判断，秒出结果。

4. 谓语动词的标志与抽象

学会了识别非谓语，还要能识别谓语动词。谓语动词有强烈的标志，需要抽象归类：

动词原形 抽象归类 说明
write do 动词原形 → 抽象成 do
goes does 第三人称单数 → 抽象成 does（谓语标志）
is be / is be动词 → 强烈的谓语标志
did did 过去时 → 谓语标志
had finished did（谓语） 过去完成时 → had 是助动词（谓语），finished 是非谓语
核心易错点：had 的双重身份
- had 的过去式是 had，过去分词也是 had（ABB 型：have-had-had）
- 所以单看 had，不能确定是谓语还是非谓语
- 但 had finished 中，had 是过去完成时的助动词 → 谓语；finished 是过去分词 → 非谓语
- 过去完成时 = had + done，所以 had 后面一定是 done 形式

5. be动词的非谓语形式

be动词也有三种非谓语形式，需要单独记忆：

非谓语形式 be动词的对应 说明
to do to be to + be（be 是动词原形）→ 非谓语
doing being 以 -ing 结尾 → 非谓语
done been be 的过去分词 → 非谓语
be动词的三种非谓语形式：to be / being / been，看到就可以直接判断为非谓语。

6. 动词过去式和过去分词的变化类型

判断一个词是谓语（did）还是非谓语（done），需要了解动词的变化类型。老师总结了四种变化类型：

变化类型 说明 例子 判断
ABB 型 过去式和过去分词一样 have → had → had had 既可以是谓语（did），也可以是非谓语（done）
ABA 型 原形和过去分词一样 come → came → come come 既可以是原形（do），也可以是过去分词（done）
AAA 型 三形都一样 let → let → let let 可以是 do / did / done，需要看语境
ABC 型 三形都不一样（不规则变化） go → went → gone / write → wrote → written 三形不同 → 看到过去分词形式 = 非谓语（done）
核心要点：
- ABB/ABA/AAA 型的词，过去式和过去分词长得一样，单看形式无法区分谓语和非谓语，需要看语境
- ABC 型的词，过去分词有独特的形式（如 gone / written / drunk），看到就一定是非谓语
- had finished → had 是谓语（过去完成时的助动词），finished 是非谓语（过去分词）

7. 谓语 vs 非谓语：如何分辨？

当遇到一个词既可能是谓语（did）又可能是非谓语（done）时，怎么分辨？老师用 make 举例：

例句对比

She made the cake.（她做了蛋糕。）
→ she 是主语，made 是谓语（过去时）
→ she 主动做蛋糕 → made 是谓语（did）
The cake made by her is good.（她做的蛋糕很好吃。）
→ the cake 是主语，is 是谓语
→ made by her 修饰 cake → made 是非谓语（done）

分辨方法一：找谓语

✅ 一个简单句只能有一个谓语
✅ 如果句中已有谓语（is），那 made 就不是谓语 → 是非谓语

分辨方法二：主动 vs 被动

✅ She made the cake → she 主动做 → made 是 did（谓语）
✅ the cake made by her → cake 被做 → made 是 done（非谓语）
核心分辨方法：
1. 找谓语法：句中已有谓语动词 → 另一个同类形式就是非谓语
2. 主动/被动法：主动 → did（谓语）；被动 → done（非谓语）
3. 句子成分法：made by her 是定语，修饰名词 → 非谓语做定语

8. 综合秒判练习

老师用抽象思维，对一堆词进行快速分类——谓语还是非谓语：

原词 抽象归类 判断 理由
to be happy to do 非谓语 to + 动词原形

has does 谓语 第三人称单数形式

9. 核心判断逻辑总结

老师反复强调用抽象思维判断非谓语的核心逻辑：

不看意思，不看后面，只看前面！三秒判断！

三秒判断法

步骤 操作
第一步 看前面两个字母是不是 to → 是 → to do → 非谓语
第二步 看以什么结尾 → 以 -ing 结尾 → doing → 非谓语
第三步 看是不是过去分词（尤其 ABC 型不规则变化）→ done → 非谓语

谓语 vs 非谓语 速查

形式 可能是谓语？ 可能是非谓语？ 判断方法
to do / to be ❌ ✅ to + 动词原形 → 一定是非谓语
doing / being ❌ ✅ 以 -ing 结尾 → 一定是非谓语
done / been / gone ❌ ✅ 过去分词（ABC型）→ 一定是非谓语
did / does ✅ ❌ 过去时/第三人称单数 → 一定是谓语
is / am / are / was / were ✅ ❌ be动词 → 一定是谓语
had ✅ ✅ 需看语境：had done → had是谓语，done是非谓语
核心口诀：
- to 开头 → to do → 非谓语
- -ing 结尾 → doing → 非谓语
- 过去分词（尤其 ABC 型）→ done → 非谓语
- be 动词 / did / does → 谓语标志
- had 看语境：had finished → had（谓语）+ finished（非谓语）

🎓 学习建议总结

  1. 建立抽象思维：学非谓语不要用死记硬背，要用"牛顿式思维"——透过表面现象看本质。不要被 to have been stolen、having been reported 等复杂形式迷惑，只看前面两个字母或最后三个字母。
  2. 三秒判断法：to 开头 → to do → 非谓语；-ing 结尾 → doing → 非谓语；过去分词（ABC型）→ done → 非谓语。不看意思，不看后面，只看前面！
  3. 记住 be 动词的非谓语形式：to be / being / been，看到就可以直接判断为非谓语。
  4. 掌握动词变化类型：ABC 型（三形不同）最容易判断，过去分词一定是非谓语。ABB/ABA/AAA 型的词需要看语境来判断是谓语还是非谓语。
  5. had 的双重身份：had finished 中，had 是过去完成时的助动词（谓语），finished 是过去分词（非谓语）。过去完成时 = had + done，所以 had 后面一定是 done 形式。
  6. 分辨谓语 vs 非谓语的方法：① 找谓语法（一句一谓语）；② 主动/被动法（主动=did，被动=done）；③ 句子成分法（定语修饰名词→非谓语）。
  7. 思维方式转变：本节课最重要的是改变思维方式。一旦视角转换过来，再看非谓语简直是清晰无比。这是"上帝视角"——站在高处看问题，一目了然。
