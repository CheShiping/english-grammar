【G05】指示代词：this / that / these / those

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G05 是「基础语法」系列第5课，由陈老师主讲。本节课讲解指示代词（Demonstrative Pronouns），这是代词四种类型（人称代词、指示代词、不定代词、疑问代词）中的第二种。

指示代词一共就四个：this、that、these、those。从名字就可以看出——它既有"指示"作用（这个、那个），又有"代替"作用（代替一个东西），所以叫"指示代词"。

虽然指示代词本身比较简单，但本节课有一个非常重要的进阶用法——that/those 指代"同类不同个"的东西，这在比较句中非常常见，也是考试高频考点。
前置知识要求：
本节课建立在 G01「名词短语」和 G03「可数名词 VS 不可数名词」的基础上。需要理解可数名词的单复数变化、不可数名词的概念，以及名词短语的构成。

2. 四个指示代词的核心区别

四个指示代词的区别非常简单，就看两个维度：距离远近和单复数。

单数 复数
近指（说话人旁边） this（这个） these（这些）
远指（说话人较远） that（那个） those（那些）
记忆口诀：this/these = 这个/这些（近），that/those = 那个/那些（远）。单复数变化规律和其他词一致：this→these，that→those。

3. 基础用法：简单指代

最基本的用法就是直接指代某个东西，配合相应的动词形式。

this / that（单数 → is）

✅ This is a book.（这是一本书。→ 近的）
✅ That is a book.（那是一本书。→ 远的）

these / those（复数 → are）

✅ These are books.（这些是书。→ 近的复数）
✅ Those are books.（那些是书。→ 远的复数）
主谓一致！
this / that + is（单数）
these / those + are（复数）
不能搞混！不能说 "this are" 或 "these is"。

4. 进阶用法：that / those 指代"同类不同个"

这是本节课最重要的用法。that 和 those 不仅可以指代前面提到的同一个东西，还可以指代同类但不同个的东西。

核心逻辑：避免重复

英语不喜欢重复。当你要比较两个同类事物时，第二个同类事物用 that / those 来替代，避免重复说出同一个名词。

关键原则：英语是一门很严谨的语言，比较的时候一定要同级比较（同类相比）。不能拿A的某个属性和B的另一个属性比。

场景一：that 指代不可数名词（单数）

✅ The weather of Chengdu is cooler than that of Chongqing.
→ 完整形式：The weather of Chengdu is cooler than the weather of Chongqing.
→ that 替代了 the weather（不可数名词，用 that 单数）
成都的天气比重庆的天气凉快。这里 that = the weather。因为 weather 是不可数名词，所以用 that（单数）来替代，动词用 is。
✅ 成都的天气 ≠ 重庆的火锅！必须天气比天气，不能跨类比较。

场景二：those 指代可数名词复数

✅ The oranges of Huainan are sweeter than those of Huaibei.
→ 完整形式：The oranges of Huainan are sweeter than the oranges of Huaibei.
→ those 替代了 the oranges（可数名词复数，用 those 复数）
"橘生淮南则为橘，橘生淮北则为枳"——淮南的橘子比淮北的橘子甜。这里 those = the oranges。因为 oranges 是可数名词复数，所以用 those（复数）来替代，动词用 are。

that / those 指代规则总览

替代词 替代对象 动词形式 例句
that 可数名词单数 / 不可数名词 is / was ...than that of Chongqing.
those 可数名词复数 are / were ...than those of Huaibei.
核心判断步骤：
1. 先看要替代的名词是单数还是复数（或不可数）
2. 可数名词单数 / 不可数 → 用 that
3. 可数名词复数 → 用 those
4. 动词跟着走：that → is，those → are

5. 综合例句解析

例句一：This is a book.

✅ This is a book.（这是一本书。→ 近的）
this 指代近处的单数事物，配合 is（单数动词）。

例句二：That is a book.

✅ That is a book.（那是一本书。→ 远的）
that 指代远处的单数事物，同样配合 is。

例句三：These are books.

✅ These are books.（这些是书。→ 近的复数）
these 指代近处的复数事物，配合 are（复数动词）。注意 book 要变 books。

例句四：Those are books.

✅ Those are books.（那些是书。→ 远的复数）
those 指代远处的复数事物，配合 are。

例句五：The weather of Chengdu is cooler than that of Chongqing.

✅ The weather of Chengdu is cooler than that of Chongqing.（成都的天气比重庆的天气凉快。）
that = the weather（不可数名词，用 that）。注意同级比较：天气比天气，不是天气比火锅！

例句六：The oranges of Huainan are sweeter than those of Huaibei.

✅ The oranges of Huainan are sweeter than those of Huaibei.（淮南的橘子比淮北的橘子甜。）
those = the oranges（可数名词复数，用 those）。"橘生淮南则为橘，橘生淮北则为枳"的经典用法。

6. 指示代词与名词短语的关系

指示代词本身就可以充当名词短语的限定词（G01 学的七种限定词之一）。

指示代词 在名词短语中的角色 示例
this 限定词（近指单数） This book is good.（这本书很好。）
that 限定词（远指单数） That book is good.（那本书很好。）
these 限定词（近指复数） These books are good.（这些书很好。）
those 限定词（远指复数） Those books are good.（那些书很好。）
结合 G01 学的名词短语知识：指示代词 + 形容词 + 名词 → 构成完整的名词短语。例如 this good book、that beautiful girl、these interesting stories、those old friends。

7. 课程总结思维导图

指示代词（this / that / these / those） ├── 核心区别：距离 × 单复数 │ ├── 近 + 单数 → this（这个） │ ├── 远 + 单数 → that（那个） │ ├── 近 + 复数 → these（这些） │ └── 远 + 复数 → those（那些） ├── 基础用法：直接指代 + 主谓一致 │ ├── this/that + is │ └── these/those + are └── 进阶用法：that/those 指代"同类不同个" ├── that → 替代可数名词单数 / 不可数名词 │ └── The weather of Chengdu is cooler than that of Chongqing. └── those → 替代可数名词复数 └── The oranges of Huainan are sweeter than those of Huaibei. └── 核心原则：同级比较（同类相比），避免重复

🎓 学习建议总结

  1. 记住四词区别：this(近单)/that(远单)/these(近复)/those(远复)，看距离和单复数两个维度。
  2. 主谓一致：this/that + is，these/those + are，不能搞混。
  3. 进阶用法是重点：that/those 指代"同类不同个"的东西，避免重复。that 替代单数/不可数，those 替代复数。
  4. 同级比较原则：比较时必须同类相比（天气比天气，不是天气比火锅）。
  5. 动词跟着走：用了 that → 动词用单数（is/was），用了 those → 动词用复数（are/were）。
  6. 循序渐进积累：按照学习路线图一步步走，在课文中观察指示代词的用法，保证不走弯路。
