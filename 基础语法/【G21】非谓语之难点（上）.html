【G21】非谓语之难点（上）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G21 是「基础语法」系列第21课，由陈老师主讲。本节课是动词部分的实战练习课，专门讲解如何综合运用非谓语知识找出谓语、改正错误。

在此之前，同学们已经学习了非谓语的基础概念（G19，抽象思维秒判三种形式）、非谓语的本质（G20，不定式=不确定、动名词=确定、现在分词=分身、过去分词=完成）。本节课将前面所有知识融会贯通，通过大量实战练习，彻底掌握"找谓语→改非谓语"的完整解题流程。

本节课的核心目标：掌握找谓语的两种方法（正面找 + 正难则反），运用"一山不容二虎"原则判断是否需要非谓语，再根据非谓语的本质选择正确的形式。
前置知识要求：
本节课建立在 G12「动词分类」、G15「谓语的构成」、G19「非谓语之上帝视角」、G20「非谓语的本质」的基础上。需要理解谓语构成的三种方式、非谓语的三种形式及其本质含义。

2. 找谓语的两种方法

老师首先演示了找谓语的两种方法，强调要"以秋风扫落叶之势"识别谓语：

方法一：正面找

直接找实义动词、系动词、助动词——看到就认出来。

✅ want → 抽象成 do → 谓语动词
✅ go → 抽象成 do → 谓语动词
✅ is → 系动词 → 谓语动词
✅ play → 抽象成 do → 谓语动词
✅ is → 系动词 → 谓语动词
✅ since → 抽象成 does（第三人称单数）→ 谓语动词
✅ was built → was（助动词）+ built（实义动词）→ 一起构成谓语
✅ has been sold out → has（助动词）+ been（助动词）+ sold out（实义动词）→ 一起构成谓语
✅ are singing → are（助动词）+ singing（实义动词）→ 一起构成谓语

方法二：正难则反（抽象思维）

排除非谓语形式后，剩下的就是谓语标志：

非谓语形式 be动词的对应 说明
to do to be 排除 to be
doing being 排除 being
done been 排除 been
把 to be、being、been 排除后，剩下的 am / is / are / was / were / be 都是非常明显的谓语标志。再加上情态动词（can / could / will / would / shall / should 等），可以快速锁定谓语。

特殊注意：ABB 型动词的双重身份

✅ wanted → want（原形）→ wanted（过去式）→ wanted（过去分词）→ ABB 型
✅ 单纯的 wanted 既可以抽象成 did（谓语），也可以抽象成 done（非谓语）
✅ 需要看语境：主动 → did（谓语）；被动 → done（非谓语）
核心易错点：
- wanted 的形式既是谓语动词形式（did），也是非谓语动词形式（done）
- 满足谓语动词的形式后，还要满足"一山不容二虎"原则才能确定它是谓语
- walked 同理：walk（原形）→ walked（过去式）→ walked（过去分词），也是 ABB 型

3. 完整的解题思路（两步法）

老师总结了非谓语题目的完整解题思路，这是本节课最重要的方法论：

步骤 操作
第一步：判断是否需要非谓语 运用"一山不容二虎"原则——看是否满足三种谓语产生条件。不满足 → 必须用非谓语
第二步：选择正确的非谓语形式 根据非谓语的本质选择：不确定 → to do；确定/长期/习惯 → doing（动名词）；与谓语同步 → doing（现在分词）；完成/被动 → done（过去分词）
核心口诀：
- 第一步：一山不容二虎 → 判断是否需要非谓语
- 第二步：非谓语的本质 → 选择正确的形式（不确定/确定/同步/完成被动）
- 两步缺一不可，这才是完整的解题思路

4. 实战练习一：Getting up early is good for health

题目分析

❌ Get up early is good for health.
→ is 是系动词，构成谓语（主系表结构）
→ get 前面没有连接词+主语 → 必须用非谓语（一山不容二虎）

选择非谓语形式

→ "早起有利于健康"是不确定的吗？不是，是一次性的吗？不是
→ 是要长期习惯性的早起才有利于健康 → 用动名词 doing
✅ Getting up early is good for health.（早起有利于健康。）
→ Getting up（动名词短语，作主语）+ is（系动词，谓语）+ good（表语）
注意：这里是动名词（doing），不是现在分词。因为"早起有利健康"表现的是长期习惯性的东西，不是与谓语同步发生的动作。动名词作主语，看作单数。

5. 实战练习二：I want to go

题目分析

✅ I want to go.
→ I 是主语，名正言顺产生一个谓语 want
→ go 前面没有连接词+主语 → 必须用非谓语（一山不容二虎）

选择非谓语形式

→ "我想回家" → 想回家了就能回家吗？不一定能回得了
→ 回家这件事是不确定的 → 用不定式 to do
核心辨析：想 vs. 回去
- "想"是谓语（want），肯定是确定的
- "回去"是不确定的——想回去不一定能回去
- 不能偷换概念，把"想"的确定性套在"回去"上
✅ I want to go.（我想去。）
→ want（谓语）+ to go（不定式，作宾语）

6. 实战练习三：My favorite sport is play football

题目分析

❌ My favorite sport is play football.
→ is 是系动词，构成谓语（主系表结构）
→ play 前面没有连接词+主语 → 必须用非谓语

选择非谓语形式

→ "我最喜欢的运动" → 难道是踢一次吗？不是
→ 是长期的爱好 → 用动名词 doing
✅ My favorite sport is playing football.（我最喜欢的运动是踢足球。）
→ is（谓语）+ playing football（动名词短语，作表语）

7. 实战练习四：There is a bird singing

题目分析

❌ There is a bird sings.
→ There is 是谓语（there be 句型，表示存在）
→ sings 前面没有连接词+主语 → 必须用非谓语

选择非谓语形式

→ "有一只鸟正在唱歌" → 唱歌是与 is（存在）同步发生的动作
→ 与谓语同步发生 → 用现在分词 doing
✅ There is a bird singing.（有一只鸟在唱歌。）
→ is（谓语）+ singing（现在分词，作伴随状语，与 is 同步发生）
核心区分：动名词 vs. 现在分词
- 练习二、三的 doing 是动名词（确定/长期/习惯）
- 这里的 singing 是现在分词（与谓语同步发生）
- 虽然形式一样（都是 -ing），但本质不同！

8. 实战练习五：The boy sits over there like singing

题目分析

❌ The boy sits over there like singing.
→ 这句话有两种可能的理解，需要分辨

分辨方法一：缩句法

→ 主干：男孩喜欢唱歌 → the boy likes singing
→ sits → 谓语动词（改为 likes）；like → 非谓语（改为 sitting，做后置定语修饰 boy）

分辨方法二：缩小范围法（定语判断）

→ "the boy" 是很笼统的（所有男孩）
→ "坐在那边的"把范围变小了 → 是定语 → 定语 = 非谓语
→ sits 用了一个谓语的形式 → 错了 → 要改成非谓语

选择非谓语形式

→ to do（不确定）？男孩坐在那边不确定吗？排除
→ 动名词 doing（长期习惯）？不是长期坐在那边的 → 排除
→ 现在分词 doing（与谓语同步）？正坐在那边的 → 对了！
✅ The boy sitting over there likes singing.（坐在那边的男孩喜欢唱歌。）
→ sitting over there（现在分词短语，作后置定语，修饰 boy）+ likes（谓语）+ singing（动名词，作宾语）
专业术语：sitting over there 叫"现在分词短语做后置定语"，修饰 boy。singing 是动名词，作 likes 的宾语。同一个 -ing 形式，在这里分别是现在分词和动名词，本质不同！

9. 实战练习六：The house was built last year has been sold out

题目分析

❌ The house was built last year has been sold out.
→ 缩句：房子已经出售 → has been sold out 才是谓语
→ was built 前面没有连接词+主语 → 必须用非谓语

选择非谓语形式

→ to do（不确定）？去年建的房子 → 不是不确定的 → 排除
→ 动名词 doing（长期习惯）？去年建的 → 不是长期的 → 排除
→ 现在分词 doing（同步发生）？建的时候已经出售了？不可能 → 排除
→ 过去分词 done（完成+被动）？房子被建 → 有被动 → 对了！

怎么把 was built 变成 built？

→ was built = be + done（被动语态）
→ 要把 be + done 变成 done → 把 be 去掉就完了！
→ 最厉害的改法就是去掉 was → built 就是过去分词
✅ The house built last year has been sold out.（去年建造的房子已经被出售了。）
→ built last year（过去分词短语，作后置定语，修饰 house）+ has been sold out（谓语，现在完成时被动语态）
核心技巧：be + done → done
- was built → 去掉 was → built（过去分词）
- are singing → 去掉 are → singing（现在分词）
- 把 be 动词去掉，剩下的就是非谓语的 doing/done 形式
- 这是最简单的改法！

10. 实战练习七：The girls are singing over there are my classmates

题目分析

❌ The girls are singing over there are my classmates.
→ 缩句：女孩是我的同学 → are（第二个）才是谓语
→ are singing 前面没有连接词+主语 → 必须用非谓语

与练习六的对比

练习 原句错误 改法 结果
练习六 was built（be + done） 去掉 was built（过去分词，被动）
练习七 are singing（be + doing） 去掉 are singing（现在分词，同步发生）
✅ The girls singing over there are my classmates.（在那边唱歌的女孩是我的同学。）
→ singing over there（现在分词短语，作后置定语，修饰 girls）+ are（谓语）+ my classmates（表语）
singing over there 与练习五的 sitting over there 同理——都是现在分词短语做后置定语。把 be 动词去掉就完了！

11. 实战练习八：My parents wanted him work out

题目分析

❌ My parents wanted him work out.
→ wanted 是谓语（ABB 型：want-wanted-wanted，主动 → did → 谓语）
→ work 前面没有连接词+主语 → 必须用非谓语（一山不容二虎）

选择非谓语形式

→ "我父母想让他努力学习" → 他一定会努力学习吗？不一定！
→ 哪个父母不想让孩子努力学习？想，但不一定实现 → 不确定的 → 用不定式 to do
✅ My parents wanted him to work out.（我父母想让他努力学习。）
→ wanted（谓语）+ him（宾语）+ to work out（不定式，作宾语补足语）
从公式角度：want somebody to do something。但从本质角度理解：想让他做 → 不一定做得到 → 不确定 → to do。这才是本质的思维方式，而不是死记硬背公式。

13. 核心判断逻辑总结

老师反复强调解题的核心逻辑：

第一步：一山不容二虎 → 判断是否需要非谓语
第二步：非谓语的本质 → 选择正确的形式

改法速查

原句中的错误形式 改法 结果
be + doing（进行时） 去掉 be doing（现在分词/动名词）
be + done（被动语态） 去掉 be done（过去分词）
谓语动词原形/第三人称单数/过去式 根据本质选择 to do / doing / done 对应的非谓语形式
核心口诀：
- 看到 be + doing/done → 去掉 be 就完了
- 看到普通谓语动词 → 根据本质选非谓语形式
- 不确定/将来/目的 → to do
- 确定/长期/习惯 → doing（动名词）
- 与谓语同步 → doing（现在分词）
- 已完成 → done（过去分词）
- vi done → 只表完成；vt done → 表完成 + 被动

🎓 学习建议总结

  1. 掌握找谓语的两种方法：正面找（直接识别实义动词/系动词/助动词）+ 正难则反（排除 to be/being/been 后剩下的就是谓语标志）。两者结合，以秋风扫落叶之势锁定谓语。
  2. 牢记完整的解题两步法：第一步：一山不容二虎 → 判断是否需要非谓语；第二步：非谓语的本质 → 选择正确的形式。两步缺一不可。
  3. 掌握改法速查：be + doing/done → 去掉 be 就完了。这是最简单的改法。
  4. 区分动名词和现在分词：虽然都是 -ing，但动名词=确定/长期/习惯（可作主语/宾语），现在分词=与谓语同步发生（作伴随状语/定语）。判断方法：看它在句中的功能。
  5. ABB 型动词的双重身份：wanted/walked 等 ABB 型动词，既可以是谓语形式（did）也可以是非谓语形式（done），需要看语境判断主动还是被动。
  6. 本质思维：不要死记硬背 "want to do / like doing"，而是理解背后的逻辑——want to do 因为"想去做"是不确定的；like doing 因为"喜欢做"是长期习惯的。
  7. 缩句法辅助判断：当句子结构复杂时，用缩句法找出主干（主语+谓语+宾语），剩下的部分就是定语/状语等非谓语成分。
