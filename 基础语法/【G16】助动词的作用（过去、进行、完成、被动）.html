【G16】助动词的作用（过去、进行、完成、被动）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G16 是「基础语法」系列第16课，由陈老师主讲。本节课是动词部分的核心深入课，专门讲解助动词的具体辅助作用——即助动词在句子中到底"帮忙"做了什么。

在此之前，同学们已经学习了动词分类（G12）、be动词辨析（G13）、及物动词与不及物动词（G14）、谓语的构成（G15）。本节课将聚焦助动词，彻底搞清楚助动词的六大辅助作用。

本节课的核心目标：彻底搞清楚助动词的六大辅助作用——构成时态（进行/完成）、构成否定和疑问、构成被动语态、构成强调，以及区分助动词和实义动词。
前置知识要求：
本节课建立在 G12「动词分类」、G15「谓语的构成」的基础上。需要理解助动词的四类（be动词、情态动词、狭义助动词、完成助动词），以及助动词+实义动词/系动词构成谓语的规则。

2. 核心回顾：助动词的分类与组合规则

在讲助动词的具体作用之前，老师先快速回顾助动词的分类和组合规则：

助动词的四类

类别 成员 后接形式
be动词 am / is / are / was / were / be doing（进行）或 done（被动）
情态动词 can / could / will / would / shall / should / may / might / must / need / dare / had better 动词原形
狭义助动词 do / does / did do（动词原形）
完成助动词 have / has / had done（过去分词）

助动词的组合规则

✅ 最多三个助动词 + 一个实义动词
✅ 情态动词 + have/has/had + be + doing/done + 实义动词
助动词可以叠加，但最多三个。最核心的实义动词只有一个——因为实义动词是"外科医生"，做具体动作的。

3. 核心前提：助动词 vs 实义动词的区分

在讲助动词的作用之前，老师强调了一个基本判断方法——把助动词去掉，看句子是否还成立：

✅ You can help me. → 去掉 can → You help me.（成立）→ can 是助动词，help 是实义动词
✅ You can help me. → 去掉 help → You can me.（不成立！）→ help 不能单独构成谓语 → help 是实义动词
核心判断方法：
- 去掉后句子成立 → 该词是助动词（辅助作用）
- 去掉后句子不成立 → 该词是实义动词（核心动作）
- 助动词不能单独构成谓语，必须和实义动词/系动词一起配合

4. 助动词的辅助作用一：帮助构成时态

助动词的第一个核心作用是帮助构成时态——包括进行体和完成体。

构成进行时（be + doing）

✅ The boy is crying.（男孩正在哭。）
→ is（be动词，助动词）+ crying（实义动词，具体动作是"哭"）
→ is 的辅助作用：帮助构成进行

构成完成时（have + done）

✅ He has arrived.（他已经到达了。）
→ has（完成助动词）+ arrived（实义动词，具体动作是"到达"）
→ has 的辅助作用：帮助构成完成

构成完成进行时（have + been + doing）

✅ I have been painting all day.（我一整天都在画画。）
→ have（完成助动词，起完成作用）+ been（be动词，助动词，起进行作用）+ painting（实义动词，具体动作是"画画"）
→ have 帮助构成完成，been 帮助构成进行 → 完成进行时
关键逻辑：实义动词才是发出具体动作的词（crying、arrived、painting），而助动词（is、has、have、been）只是"护士"，辅助表示时态。

5. 助动词的辅助作用二：帮助构成否定和疑问句

助动词的第二个核心作用是帮助构成否定句和疑问句——这主要是狭义助动词（do/does/did）的功能。

构成疑问句

✅ Does he like English?（他喜欢英语吗？）
→ does（狭义助动词，起疑问作用）+ like（实义动词，具体动作是"喜欢"）
→ does 提到主语前面 → 构成疑问句

构成否定句

✅ He doesn't have a long neck.（他没有长脖子。）
→ doesn't（狭义助动词，起否定作用）+ have（实义动词，具体动作是"有"）
→ 注意：这里的 have 是实义动词（有），不是助动词！
核心易错点：He doesn't have a long neck.
很多同学看到 have 就以为是助动词，这是错误的！这里的 have 是实义动词（拥有），doesn't 才是助动词（起否定作用）。判断方法：去掉 doesn't → He have a long neck.（语法上需要改为 has，但意思成立）→ doesn't 是助动词，have 是实义动词。

6. 助动词的辅助作用三：帮助构成被动语态

助动词的第三个核心作用是帮助构成被动语态——be + done 表示被动。

一般现在时被动

✅ Trees are planted in spring.（树在春天被种下。）
→ are（be动词，助动词，起被动作用）+ planted（实义动词，具体动作是"种"）

现在完成时被动

✅ The house has been pulled down.（房子已经被推倒了。）
→ has（完成助动词，起完成作用）+ been（be动词，起被动作用）+ pulled down（实义动词，具体动作是"推倒"）
被动语态的核心公式：be + done。be 动词在这里起被动作用，而 have/has/had 如果出现在被动语态中，则是帮助构成完成时。所以 has been pulled down = has（完成）+ been（被动）+ pulled down（实义动词）。

7. 助动词的辅助作用四：帮助虚拟（预告下节课）

老师提到助动词还有一个作用是帮助构成虚拟语气，但这个知识点比较复杂，留到下一节课（虚拟与倒装）详细讲解。

8. 助动词的辅助作用五：帮助强调

助动词的第五个核心作用是帮助强调——用 do/does/did 加动词原形来表示"确实……"

✅ He did come yesterday.（他昨天确实来了。）
→ 一般过去时可以直接说 He came yesterday.（他昨天来了。）
→ 加 did + 动词原形 → He did come yesterday.（强调"确实来了"）
→ did（狭义助动词，起强调作用）+ come（实义动词，动词原形）
核心要点：
- 强调用 do/does/did + 动词原形
- did 是助动词（起强调作用），come 是实义动词（具体动作）
- 强调句的意思比一般过去时更强，表示"确实……"

9. 核心实战：区分助动词与实义动词

老师给出了一系列句子，让同学们判断每个词是助动词还是实义动词，并指出助动词起了哪种辅助作用。

实战例句逐一分析

例句 词 词性 辅助作用
Does he like swimming? Does 助动词 疑问（提到主语前构成疑问句）
He likes swimming. likes 实义动词 具体动作"喜欢"
He does like swimming. does 助动词 强调（"确实喜欢"）
Where does he live? does 助动词 疑问
He does some washing. does 实义动词 具体动作"做（洗衣服）"
I have had supper already. have 助动词 完成（"已经"）
I have had supper. had 实义动词 具体动作"吃"
The bridge has been built on... has 助动词 完成
The bridge has been built. been 助动词 被动（be + done 表被动）
I have been waiting for you. been 助动词 进行（be + doing 表进行）
I have been waiting for you. waiting 实义动词 具体动作"等"
He was struck by a stone. was 助动词 被动（be + done）
He was struck by a stone. struck 实义动词 具体动作"击中"
核心易错点汇总：
1. He does some washing. → does 是实义动词（做洗衣服的事），不是助动词！
2. I have had supper. → 第一个 have 是助动词（完成），第二个 had 是实义动词（吃）
3. The bridge has been built. → has 是助动词（完成），been 是助动词（被动），built 是实义动词（建）
4. I have been waiting. → have 是助动词（完成），been 是助动词（进行），waiting 是实义动词（等）

10. be + doing / be + done 快速判断表

老师提供了一个快速判断 be 动词辅助作用的技巧：

结构 be 的辅助作用 时态/语态 例句
be + doing 进行 进行时 He is crying.
be + done 被动 被动语态 He was struck by a stone.
have + been + doing have（完成）+ been（进行） 完成进行时 I have been waiting for you.
have + been + done have（完成）+ been（被动） 完成被动语态 The bridge has been built.
快速判断口诀：be 后面接 doing → 进行；be 后面接 done → 被动。have/has/had 出现 → 完成。

11. 助动词六大辅助作用总览

序号 辅助作用 主要使用的助动词 核心标志
1 构成时态（进行） be动词（is/are/was/were + doing） be + doing
2 构成时态（完成） 完成助动词（have/has/had + done） have + done
3 构成否定和疑问 狭义助动词（do/does/did） do/does/did 提前或加 not
4 构成被动语态 be动词（be + done） be + done
5 构成虚拟语气 情态动词等 （下节课详细讲解）
6 构成强调 狭义助动词（do/does/did + 动词原形） do/does/did + 动词原形

🎓 学习建议总结

  1. 牢记助动词的六大辅助作用：构成时态（进行/完成）、构成否定和疑问、构成被动语态、构成虚拟、构成强调。这是全课的核心框架。
  2. 区分助动词和实义动词的核心方法：去掉后句子成立 → 助动词；去掉后不成立 → 实义动词。如 He does some washing 中，去掉 does → He some washing（不成立），但 does 在这里是实义动词（做），不是助动词。
  3. be + doing → 进行；be + done → 被动：这是快速判断 be 动词辅助作用的口诀。have/has/had 出现 → 完成。
  4. 注意多助动词叠加：I have been waiting. → have（完成助动词）+ been（be动词，进行作用）+ waiting（实义动词）。最多三个助动词。
  5. 核心易错：He does some washing. → does 是实义动词！不是助动词。do 做实义动词时，意思是"做（某事）"，如 do some washing（洗衣服）、do homework（做作业）。
  6. 核心易错：I have had supper. → 两个 have/had 词性不同！第一个 have 是助动词（完成），第二个 had 是实义动词（吃）。
  7. 强调句公式：do/does/did + 动词原形。He did come yesterday.（他昨天确实来了。）
  8. 被动语态公式：be + done。The bridge has been built. → has（完成）+ been（被动）+ built（实义动词）。
