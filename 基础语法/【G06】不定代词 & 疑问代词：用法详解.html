不定代词 & 疑问代词：用法详解

基础语法 · 第 G06 课 · 陈老师语法系列整理与注释版。

G06 基础语法 陈老师系列

【G06】不定代词 & 疑问代词：用法详解

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G06 是「基础语法」系列第6课，由陈老师主讲。本节课讲解不定代词（Indefinite Pronouns）和疑问代词（Interrogative Pronouns），这是代词四种类型中的第三种和第四种。

老师指出：不定代词应该是大家最恼火的一种，因为对这个很不熟悉。本节课先简单梳理哪些是不定代词，后面会讲更精确的具体用法。

本节课是代词四大类型的收官之课。在此之前已经学了：第一种人称代词（G04）、第二种指示代词（G05）。本节课学完不定代词和疑问代词后，四种代词就全部讲完了。
前置知识要求：
本节课建立在 G01「名词短语」的基础上。需要理解名词短语的构成（限定词 + 修饰词 + 主体词）以及七种限定词。因为代词（指示代词、不定代词、疑问代词、人称代词的形物代）都属于限定词大家族。

2. 不定代词的核心特征

不定代词的名字就揭示了它的本质——它"带一个东西"，但又"不确定"是什么东西。

✅ some → 带一些，但"一些"到底是什么、多少个，不知道
✅ many → 很多，但"很多"是多少个？不知道
✅ much → 很多（不可数），但到底有多少？不知道
"不定"的含义就是：我知道它"带"了某个东西，但我不知道具体是什么、有多少。这种"不确定性"是不定代词的核心特征。

3. 不定代词家族成员一览

不定代词家族成员众多，老师逐一介绍如下：

第一组：some / any / every / each / no

代词 含义 说明
some 一些 肯定的"一些"，具体是什么/多少个不确定
any 任何 some 的否定和疑问形式
every 每一个 三者及三者以上"每一个"
each 每一个 两者或两者以上"每一个"（强调个体）
no 没有一个 完全否定，"一个都没有"

第二组：both / either / neither

代词 含义 说明
both 两者都 两个都（肯定）
either 两者之一 两个中的任意一个
neither 两者都不 两个都没有（否定）

第三组：all / none

代词 含义 说明
all 三者及三者以上都 三个或更多"全部"
none 三者及三者以上都不 三个或更多"一个都没有"

第四组：many / much / more / most

代词 含义 说明
many 很多 修饰可数名词复数
much 很多 修饰不可数名词
more 更多的 many/much 的比较级
most 最多 many/much 的最高级
many 和 much 虽然意思是"很多"，但到底是多少个/多少？不知道 → 所以是不定代词。many 修饰可数名词，much 修饰不可数名词，这是核心区别。

第五组：little / a little / few / a few

代词 含义 修饰对象 感情色彩
little 很少，几乎没有了 不可数名词 否定（几乎没有）
a little 一些 不可数名词 肯定（还有一些）
few 很少，几乎没有了 可数名词复数 否定（几乎没有）
a few 一些 可数名词复数 肯定（还有一些）
核心区分：有 a 和没 a 的区别！
- 有 a（a little / a few）→ 表示比较肯定的概念 → "还有一些"
- 没 a（little / few）→ 表示否定概念 → "几乎没有了"
- little / a little 修饰不可数名词
- few / a few 修饰可数名词复数

第六组：other 家族

代词 词性/形式 说明
other 形容词 其他的（后面必须加名词）
others 代词 其他的人/物（= other + 名词复数，后面不能再加名词）
another 形容词/代词 另一个（= an + other，用于三者及以上）
the other 形容词/代词 另一个（特指两者中的另一个）
the others 代词 其余的所有（特指两者以上中"剩下的全部"）
other 本身是形容词，后面必须加名词。others = other + 名词复数，相当于一个代词，后面不能再加名词。another = an + other，表示"另一个"。the other / the others 是特指形式。

其他常见不定代词

代词 含义 说明
half 一半 固定用法，可以当做不定代词
several 几个 修饰可数名词复数

4. 复合不定代词（12个，4×3=12）

复合不定代词由两部分构成：前缀（every / some / any / no）+ 后缀（body / thing / one）。

4 个前缀 × 3 个后缀 = 12 个复合不定代词。

前缀 \ 后缀 -body（人） -thing（事物） -one（人）
every- everybody（每个人） everything（一切） everyone（每个人）
some- somebody（某人） something（某事） someone（某人）
any- anybody（任何人） anything（任何事） anyone（任何人）
no- nobody（没人） nothing（没事） no one（没人）
记忆方法：4 个前缀 × 3 个后缀 = 12 个词，很简单。其中 -body 和 -one 都指人，-thing 指事物。some- 系列通常用于肯定句，any- 系列通常用于疑问句和否定句，no- 系列本身自带否定含义。
注意拼写：
- no one 是两个词（中间有空格），不是 "noone"
- nobody 是一个词（中间没有空格），不是 "no body"
- everyone / everybody 意思相同，可以互换使用

5. 疑问代词（Interrogative Pronouns）

疑问代词是代词四种类型中的第四种。它的核心特征是：它要带一个东西，同时又要表疑问。

核心机制：提问 = 调序

疑问代词的本质是：它本来在句中"带一个东西"（充当某个成分），但为了提问，把它提到句首，从而构成疑问句。

✅ Who is he?（他是谁？）→ 还原：He is who.（他是谁。）→ 调序 → Who is he?
✅ What do you want?（你想要什么？）→ 还原：You want what.（你想要什么。）→ 调序 → What do you want?
疑问代词本身"带一个东西"（who 带人，what 带事物），同时又有"疑问"的属性。把带东西的那个词提到句首，就构成了疑问句。

常见疑问代词

疑问代词 含义 带什么 例句
who 谁 人 Who is he?（他是谁？）
what 什么 事物 What do you want?（你想要什么？）
which 哪个 选择 Which book do you like?（你喜欢哪本书？）
whose 谁的 所属关系 Whose book is this?（这是谁的书？）
疑问代词 + 从句 = 难度升级！
如果疑问代词单独用于简单疑问句，相对简单。但如果和后面的从句结合起来（如宾语从句、主语从句），难度会上升。本节课先讲最基本的含义，更复杂的用法后面会逐步展开。

6. 代词与名词短语的完整关系图

老师最后做了一个重要的回顾：把四种代词和 G01 学的名词短语联系起来。

名词短语的三大构成

部分 名称 说明
第一部分 限定词 七种：冠词 / 形容词性物主代词 / 名词所有格 / 指示代词 / 不定代词 / 基数词 / 疑问代词
第二部分 修饰词 形容词（adj）
第三部分 主体词 名词（n）

七种限定词与代词的关系

限定词类型 与代词的关系
冠词 (a/an/the) 基数词 one 的弱化形式
形容词性物主代词 (my/your/his...) 人称代词的形容词性物主代词形式
名词所有格 ('s) 名词所有格的衍生形式
指示代词 (this/that/these/those) 代词第二种类型，本身就是限定词
不定代词 (some/any/every...) 代词第三种类型，本身就是限定词
基数词 (one/two/three) one 弱化后变成冠词 a/an
疑问代词 (what/which...) 代词第四种类型，本身就是限定词
所有代词其实都在名词短语的限定词大家族里！指示代词、不定代词、疑问代词本身就是限定词。人称代词里的形容词性物主代词也是限定词。而冠词就是基数词 one 的弱化形式。七种限定词都有千丝万缕的联系。
代词四大类型总览：
1. 人称代词（G04）→ 主格/宾格/形物代/名物代/反身代
2. 指示代词（G05）→ this/that/these/those
3. 不定代词（G06上）→ some/any/every/no/both/either/neither/all/none/much/many/little/few/other/another...
4. 疑问代词（G06下）→ who/what/which/whose

🎓 学习建议总结

  1. 理解"不定"的本质：不定代词 = "带一个东西，但不确定是什么"。抓住这个核心，就能理解为什么叫"不定"代词。
  2. 分组记忆不定代词：不要一个一个死记，按组记：some/any/every/each/no 一组，both/either/neither 一组（两者），all/none 一组（三者以上），many/much/more/most 一组，little/a little/few/a few 一组（有 a 肯定/没 a 否定），other 家族一组。
  3. 牢记有 a 和没 a 的区别：little/a little / few/a few 中，有 a 表示肯定（还有一些），没 a 表示否定（几乎没有了）。这是考试高频考点。
  4. 复合不定代词 4×3=12：前缀 4 个 × 后缀 3 个 = 12 个词，按表格规律记忆即可。注意 no one 是两个词，nobody 是一个词。
  5. 疑问代词 = 调序提问：疑问代词本来在句中"带一个东西"，提到句首就构成疑问句。who 带人，what 带事物。
  6. 代词与名词短语打通：所有代词都在名词短语的限定词大家族里，七种限定词都有千丝万缕的联系。理解这一点，语法体系就打通了。
  7. 循序渐进：不定代词的具体用法比较复杂，本节课只是入门。按照学习路线图一步步走，在课文中观察用法，保证不走弯路。
