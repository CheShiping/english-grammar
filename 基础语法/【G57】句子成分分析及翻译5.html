1. 课程背景与引入

G57 是「基础语法」系列第57课，由陈老师主讲。本节课是句子部分的实战练习课（续），紧接 G56「句子成分分析及翻译4」，继续通过5个经典例句的逐句分析，将前面所有句型知识融会贯通，进一步巩固"找谓语→判断句型→识别后置定语和状语→变序翻译"的完整操作流程。

本节课重点讲解两个高频易错考点：① 祈使句的识别（省略主语 you，不能误判为缺主语的主语从句）以及② 定语从句与同位语从句的终极辨析（以 promise 为例，通过"等同检验"区分定从和同位从），同时强化 go 的不及物属性、keep an eye on 短语谓语、It 形式主语等核心知识点。

本节课的核心目标：通过5个例句的逐句分析，巩固祈使句的识别方法、"that"引导从句时的类型判断（定从vs同位从）、go的不及物属性、It形式主语等核心技能。
前置知识要求：
本节课建立在 G40「五大基本句型」、G41「祈使句」、G43「从句/复合句1.0」、G45「从句3.0」、G52「翻译公式」、G53「句子成分分析及翻译1」的基础上。

2. 核心易错点一：祈使句的识别

老师以"Keep an eye on my little sister while I'm away"为例，揭示了同学们最容易犯的错误——一看到句子缺主语就认为是主语从句：

Keep an eye on my little sister while I'm away.
→ 句中有两个谓语：keep（谓语1）+ am（谓语2，系动词）
→ 引导词 that/while → while 是从属连词（时间），从这里划开
→ 主句：Keep an eye on my little sister → 看起来缺主语？→ 不一定！
→ 这是祈使句！祈使句省略了主语 you → 不是缺主语的主语从句 ✓
核心口诀：
- 看到句子缺主语不要激动，先想想是不是祈使句（省略了 you）
- 祈使句的特点：以动词原形开头，语气是命令/请求/建议
- Keep an eye on = 固定短语，意思是"照看/留意"
- 连接词个数 = V - 1 = 2 - 1 = 1 → while 是从属连词 → 复合句

keep an eye on 的两种理解方式

理解方式 分析 说明
整体看作短语谓语 keep an eye on = 照看（整体看作一个谓语短语） 简单理解：照看 + my little sister（宾语）→ 简单 ✓
精细拆解 keep（谓语）+ an eye（宾语）+ on my little sister（状语） 字面意思：在你妹妹身上保持一个注视 → 转换翻译为"照看" ✓
核心逻辑：建议简单理解——把 keep an eye on 整体看作一个谓语短语（照看），my little sister 是宾语。while I'm away 是时间状语从句，修饰 keep。

3. 核心易错点二：go 是不及物动词

老师以"Go where you want to go"为例，重点讲解了 go 的不及物属性对从句类型判断的影响：

Go where you want to go.
→ 句中有两个谓语：go（谓语1）+ want（谓语2）
→ 引导词 where → 从这里划开
→ 主句：Go → 看起来只有一个动词？→ 是祈使句，省略了主语 you ✓
→ go 是不及物动词（vi.）→ 后面不需要接宾语 → 主句完整 ✓
→ 主句完整 → 定从/状从/同位从 → 没有名词可修饰 → 排除定从和同位从 → 状语从句 ✓
核心辨析——go 是不及物动词：
- go 是不及物动词，后面不能直接接宾语
- go to school（加介词 to 后才能接宾语）→ 证明 go 是不及物的
- go home 中 home 是地点副词，不影响 go 的不及物属性
- 很多同学误以为 go 后面可以接宾语（如 go school），这是错误的
核心逻辑：Go where you want to go. → 祈使句 + where 引导的地点状语从句。翻译："去你想去的地方"或"你想去哪里就去吧"。

4. 核心易错点三：It 作形式主语（与主语从句对比）

老师以"That she will go is certain"为例，讲解了主语从句和 It 形式主语的转换：

That she will go is certain.
→ 两个谓语：will go（will+go原形=谓语1）+ is（系动词=谓语2）
→ that 引导从句 → 划分：[That she will go]（从句） | is certain（主句）
→ 主句：is certain → 系动词 is 后面缺表语 → 主句不完整 → 主语从句 ✓
→ 大结构：主语从句 + 系动词 + 表语 → 主系表（SVP）→ 主干不变序

主语从句的两种表达方式

表达方式 例句 说明
that 从句做主语（句首） That she will go is certain. 主语从句在句首，正式文体
It 做形式主语 It is certain that she will go. It 是形式主语，真正主语是 that 从句（避免头重脚轻）
核心逻辑：that she will go 做主语（她要走这件事）+ is（系动词）+ certain（表语，表示评价/判断）。两种表达方式意思相同，可根据中文习惯灵活选择。

5. 例句一：Keep an eye on my little sister while I'm away.

分析过程：
① 找谓语：keep（谓语1）+ am（谓语2，系动词单独构成谓语）→ 两个谓语
② 引导词：while → 从 while 处划开
③ 主句：Keep an eye on my little sister → 祈使句（省略主语 you）→ 主谓结构完整 ✓
④ while I'm away → 时间状语从句（修饰 keep）→ "当我离开的时候"
⑤ 句型：祈使句 + 时间状语从句 → 主干不变序

翻译结果

翻译：我离开的时候，请照看一下我妹妹。

6. 例句二：Go where you want to go.

分析过程：
① 找谓语：go（谓语1）+ want（谓语2）→ 两个谓语
② 引导词：where → 从 where 处划开
③ 主句：Go → 祈使句（省略主语 you）→ go 是不及物动词 → 主句完整 ✓
④ where you want to go → 没有名词可修饰 → 排除定从和同位从 → 地点状语从句 ✓
⑤ where 引导的地点状语从句 → 修饰 go → 需要变序

翻译结果

翻译：去你想去的地方。
（或：你想去哪里就去吧。）

7. 例句三：That she will go is certain.

分析过程：
① 找谓语：will go（will+go原形=谓语1）+ is（系动词=谓语2）→ 两个谓语
② 引导词：that → 从 that 处划开
③ 从句：That she will go（主语从句）
④ 主句：is certain → 系动词 is 后面缺表语 → 主句不完整 → 主语从句 ✓
⑤ 大结构：主语从句 + is（系动词）+ certain（表语）→ 主系表（SVP）→ 主干不变序

翻译结果

直译：她要走是确定的。
符合中文习惯：很确定她要走。/ 她要走是很确定的。

8. 例句四：I remember the factory that my mother worked in.

分析过程：
① 找谓语：remember（谓语1）+ worked（谓语2）→ 两个谓语
② 引导词：that → 从 that 处划开
③ 主句：I remember the factory → 主谓宾结构完整 ✓ → 定从/状从/同位从
④ factory（工厂）不是抽象名词 → 排除同位从
⑤ 修饰关系：that my mother worked in 修饰 factory → "我妈妈曾经工作过的工厂" → 缩小范围 → 定语从句 ✓

翻译结果

变序操作：
① 定语从句 that my mother worked in → 变序（调 factory 前面）

翻译：我记得我妈妈曾经工作过的那个工厂。

9. 例句五（上）：Do you remember the promise that you would help me?

分析过程：
① 找谓语：do...remember（do是助动词+remember=谓语1）+ would help（would+help原形=谓语2）→ 两个谓语
② 注意：这是疑问语序，do 提前了 → 还原陈述句：You remember the promise that you would help me.
③ 引导词：that → 从 that 处划开
④ 主句：You remember the promise → 主谓宾结构完整 ✓ → 定从/状从/同位从
⑤ promise（承诺）是抽象名词 → 满足"抽象"条件 ✓
⑥ 等同检验：that you would help me（你会帮助我）= an promise（一个承诺）？→ 是的！"你会帮助我"本身就是一个承诺的内容 ✓
⑦ 三要素全部满足（完整+抽象+等同）→ 同位语从句 ✓

翻译结果

翻译：你还记得你会帮助我的那个承诺吗？
（同位语从句可以不变序，也可以像定语一样翻译）

10. 例句五（下）：Do you remember the promise that you made last year?

分析过程：
① 找谓语：do...remember（谓语1）+ made（谓语2，ABB型动词，主动形式=谓语）→ 两个谓语
② 引导词：that → 从 that 处划开
③ 主句：You remember the promise → 主谓宾结构完整 ✓ → 定从/状从/同位从
④ promise（承诺）是抽象名词 → 满足"抽象"条件 ✓
⑤ 等同检验：that you made last year（你去年做的）= an promise（一个承诺）？→ 不等同！✗
⑥ "你去年做的"≠ "承诺"，只是说明了"做"的时间 → 没有等同关系
⑦ 只是把"承诺"缩小了范围（你去年做的那个承诺，不是你前年做的）→ 定语从句 ✓
核心辨析——同位从 vs 定从（promise 的终极对决）：
- that you would help me（你会帮助我）→ 这是一个承诺的内容 → 等同 → 同位语从句 ✓
- that you made last year（你去年做的）→ 只是说明做的时间 → 不等同 → 缩小范围 → 定语从句 ✓
- 关键：看从句内容是否等于抽象名词的内容（等同→同位从；不等同→定从）

翻译结果

变序操作：
① 定语从句 that you made last year → 变序（调 promise 前面）
② 时间状语 last year → 变序（调 made 前面）

翻译：你还记得你去年做的那个承诺吗？

11. 五大例句完整总结表

12. 核心知识点总结

知识点一：祈使句的识别

判断维度 说明
形式特征 以动词原形开头，语气是命令/请求/建议
主语 省略了 you（不是缺主语的主语从句！）
判断方法 在句首加 "Please" 看是否通顺 → 通顺 → 祈使句
典型例句 Keep an eye on my little sister.（请照看一下我妹妹）

知识点二：go 是不及物动词

判断维度 说明
go 的词性 不及物动词（vi.），后面不能直接接宾语
接目的地 必须加介词 to：go to school / go to Beijing
例外 go home 中 home 是地点副词，不影响 go 的不及物属性
对从句判断的影响 go 后面不需要宾语 → 主句完整 → 定从/状从/同位从（不是宾从）

知识点三：It 作形式主语

表达方式 结构 例句
that 从句做主语（句首） [That ...] + 系动词 + 表语 That she will go is certain.
It 做形式主语 It + 系动词 + 表语 + that 从句 It is certain that she will go.

知识点四：定语从句 vs 同位语从句（promise 终极辨析）

对比维度 同位语从句 定语从句
三要素 完整 + 抽象 + 等同（三要素全满足） 完整 + 抽象 + 不等同（缩小范围）
等同检验 从句内容 = 抽象名词的内容 从句内容 ≠ 抽象名词的内容
that you would help me "你会帮助我" = 一个承诺 → 等同 → 同位从 ✓ ——
that you made last year —— "你去年做的" ≠ 承诺（只是时间）→ 缩小范围 → 定从 ✓
变序 不变序（同位语=同一事物，可不变序） 需要变序（调到被修饰的名词前面）
核心口诀——等同检验法：
- 同位语从句：从句内容 = 抽象名词（"你会帮助我" = "承诺"）→ 等同 → 同位从
- 定语从句：从句内容 ≠ 抽象名词（"你去年做的" ≠ "承诺"）→ 不等同 → 缩小范围 → 定从
- 抽象名词举例：promise（承诺）、idea（想法）、news（消息）、fact（事实）、hope（希望）...

14. 核心判断逻辑总结

G57 核心方法总结

第一步：找谓语动词 → 数个数 → 找连接词 → 判断句型类型
↓
第二步：看到动词原形开头 → 想想是不是祈使句（省略主语 you）
↓
第三步：看到 It 开头 / that 从句在句首 → 考虑是不是形式主语/主语从句
↓
第四步：看到 that 引导从句 → 先看主句是否完整
 完整 → 定从/状从/同位从
 不完整 → 主从/宾从/表从
↓
第五步：定从 vs 同位从 → 等同检验法
 从句内容 = 抽象名词 → 同位语从句（不变序）
 从句内容 ≠ 抽象名词 → 定语从句（需要变序）
↓
第六步：变序操作 → 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前
核心口诀：
- 谓语动词是解开所有句子的钥匙
- 看到动词原形开头要想想是不是祈使句（不要误判为缺主语的主语从句）
- go 是不及物动词（vi.），后面不接宾语
- keep an eye on = 照看（整体看作一个谓语短语）
- that she will go is certain = 主语从句 + 主系表（不变序）
- 同位从 vs 定从：等同检验法（从句内容 = 抽象名词 → 同位从；不等同 → 定从）
- promise 既可以引导同位从也可以引导定从，关键看等同关系
- 变序 = 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前

  3. 牢记 keep an eye on 的两种理解：简单理解：整体看作一个谓语短语（照看）；精细理解：keep（谓语）+ an eye（宾语）+ on my little sister（状语）→ 字面"在你妹妹身上保持注视"→ 转换翻译为"照看"。
  4. 牢记主语从句的两种表达：① that 从句做主语（句首）→ That she will go is certain. ② It 做形式主语 → It is certain that she will go. 两种表达方式意思相同。
  5. 牢记"等同检验法"区分定从和同位从：从句内容 = 抽象名词 → 同位语从句（不变序）；从句内容 ≠ 抽象名词 → 定语从句（需要变序）。promise 既可以引导同位从也可以引导定从，关键看等同关系。
  6. 牢记 ABB 型动词的判断：made 是 ABB 型动词（make-made-made），主动形式 = 谓语。需要做主动/被动判断。
  7. 翻译三步法：找谓语 → 识别句型 → 找后置定语和状语变序 → 翻译完成。每一步都不能跳过。
