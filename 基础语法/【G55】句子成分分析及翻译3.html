2. 核心易错点：that 的多重身份

老师以一个经典例句切入，揭示了同学们最容易犯的错误——一看到 that 就认为是引导词：

It was a pity that you didn't watch that wonderful football match.
→ 句中有两个 that：第一个 that 是从属连词（引导主语从句）；第二个 that 是指示代词（那个）
→ 判断方法：that 后面是否跟主谓结构？→ 第一个 that 后面是 you didn't watch（主+谓）→ 是引导词 ✓
→ 第二个 that 后面是 wonderful football match（名词短语，没有主谓结构）→ 不是引导词，是"那个"✗
核心口诀：
- 看到 that 不要激动，先看 it 后面有没有主谓结构
- that + 主谓结构 → 引导词（连词/关系代词）
- that + 名词短语 → 指示代词（"那个"），不是引导词
- 连接词个数 = V - 1，V=1 时连接词个数=0，没有引导词

that 的三种身份总结

身份 词性 判断方法 例句
从属连词（引导词） 连词，不做成分 that 后跟完整句子（主+谓） It was a pity that you didn't watch...
关系代词 代词，在从句中做成分 that 后跟主谓结构，且 that 在从句中做主/宾/表 The book that I bought...
指示代词（那个） 代词/限定词 that 后跟名词短语（无主谓结构） ...watch that wonderful football match

3. 核心易错点：It 作形式主语

老师强调，看到 It 开头 一定要考虑是不是 It 做形式主语：

It was a pity that you didn't watch the wonderful football match.
→ 去掉 It 后：___ was a pity that you didn't watch... → 主句缺主语 ✓
→ that you didn't watch the wonderful football match 是真正的主语
→ It 是形式主语，真正的主语是后面的 that 从句

It 形式主语的常见类型

真正主语类型 结构 例句
不定式（to do） It is + adj. + to do... It is hard to learn English.
动名词（doing） It is + adj. + doing... It is no use crying.
that 从句 It is + adj./noun + that... It was a pity that you didn't come.
核心辨析：
- 判断 It 是否形式主语的方法：去掉 It，看主句是否缺主语
- 去掉 It 后主句缺主语 → It 是形式主语，真正主语在后面 → 主语从句
- 去掉 It 后主句不缺主语 → It 是真正的主语（指代天气/时间/距离等）

4. 例句一：It was a pity that you didn't watch the wonderful football match.

分析过程：
① 找谓语：was（谓语1）+ didn't watch（谓语2，didn't是助动词+watch原形）→ 两个谓语
② 引导词：that → 但句中有两个 that，划哪个？
③ 第一个 that 后面是 you didn't watch（主+谓）→ 是引导词 ✓
④ 第二个 that 后面是 wonderful football match（名词短语）→ 是指示代词"那个"✗
⑤ 划分：It was a pity（主句） | that you didn't watch the wonderful football match（从句）
⑥ 看主句：It was a pity → 主系表结构，但 It 是形式主语 → 去掉 It 后缺主语 → 主语从句 ✓
⑦ 从句内部：you didn't watch the wonderful football match → 主谓宾结构 ✓
核心辨析——两个 that 的区分：
- 第一个 that：从属连词，引导主语从句，不做成分
- 第二个 that：指示代词，修饰 wonderful football match，意思是"那个精彩的足球比赛"
- 判断方法：that 后面是否跟主谓结构？跟了→引导词；跟名词短语→指示代词

翻译结果

直译：你没有看这场精彩的足球比赛是一个遗憾。
符合中文习惯：很遗憾你没有看这场精彩的足球比赛。

5. 例句二：We should do something to help the comrades in difficulties.

分析过程：
① 找谓语：should do（谓语1，should是情态动词+do原形）→ 只有一个谓语 → 简单句 ✓
② 主语：We；谓语：should do；宾语：something
③ to help the comrades in difficulties 是什么成分？
④ 主干（主谓宾）完了之后的 to do → 优先考虑是不是目的状语 ✓
⑤ to help the comrades 修饰 do → "做事情的目的是帮助同志" → 目的状语 ✓
⑥ something 是不定代词（笼统）→ 后面跟后置定语的概率很大
⑦ in difficulties（处于困难中的）修饰 comrades → 后置定语 ✓
核心辨析——to do 做目的状语 vs 后置定语：
- 主干（主谓宾）完了之后的 to do → 优先考虑目的状语
- "我们应该做一些事情"→ 目的是"去帮助同志"→ 通顺 → 目的状语 ✓
- 如果理解为"我们应该做去帮助同志的事情"→ 也通顺，但用中文辅助判断，目的状语更自然
- 口诀：主干完了的 to do → 优先考虑目的状语

翻译结果

变序操作：
① 目的状语 to help the comrades → 不变序（目的状语动作之后）
② 后置定语 in difficulties → 变序（调 comrades 前面）

翻译：我们应该做一些事情，去帮助处于困难中的同志们。

6. 例句三：You had better answer the question in English.

分析过程：
① 找谓语：had better + answer → 一起构成谓语（had better 是助动词/情态动词类）
② 为什么 had better 可以和 answer 一起？→ had better 相当于助动词，助动词+实义动词=一个谓语
③ 只有一个谓语 → 简单句 ✓
④ 主语：You；谓语：had better answer；宾语：the question
⑤ in English 是什么成分？→ 要么修饰 question，要么修饰 answer
⑥ 试一下：①"你最好回答用英语的问题"→ 不通顺 ✗ ②"你最好用英语回答问题"→ 通顺 ✓
⑦ in English 修饰 answer（动词）→ 方式状语 → 需要变序
核心辨析——had better 的谓语构成：
- had better 是固定结构，had 是助动词，better 是副词，整体相当于情态动词
- had better + 动词原形 → 一起构成谓语
- 类似结构：would rather / might as well / used to 等

翻译结果

变序操作：
① 方式状语 in English → 变序（调 answer 前面）

翻译：你最好用英语来回答这个问题。

7. 例句四：Dishes that the Chinese all over the world are hoping for (the realization for modernization).

分析过程：
① 找谓语：are hoping for（谓语1，hope 是不及物动词+for构成及物短语）→ 只有一个谓语 → 简单句
② that 是什么？→ that 后面是 the Chinese（名词短语，没有主谓结构）→ that 是关系代词，不是引导词
③ that 在从句中做成分（for 的宾语，即 hoping for 的宾语）→ 关系代词 ✓
④ all over the world 是什么成分？→ 修饰 the Chinese → 后置定语 ✓
⑤ 为什么是后置定语？→ the Chinese 是笼统名词（天下中国人很多）→ 需要缩小范围
⑥ for modernization 是什么成分？→ 修饰 realization → 后置定语 ✓
⑦ realization 是笼统名词（有很多种实现）→ for modernization 缩小范围→"四个现代化的实现"
核心辨析——that 是关系代词还是从属连词：
- that 后面跟完整句子（主+谓）→ 从属连词/关系代词
- that 后面跟名词短语（无主谓）→ 指示代词（"那个"）或关系代词
- 判断方法：that 在从句中是否做成分？→ 做成分→关系代词；不做成分→从属连词
- 本句中 that = the dishes，做 for 的宾语 → 关系代词 ✓

翻译结果

变序操作：
① 后置定语 all over the world → 变序（调 the Chinese 前面）
② 后置定语 for modernization → 变序（调 realization 前面）

翻译：全世界的中国人都在期待希望着四个现代化的实现。

8. 例句五：We must go to the meeting right now.

分析过程：
① 找谓语：must go（谓语1，must是情态动词+go原形）→ 只有一个谓语 → 简单句 ✓
② 主语：We；谓语：must go；to the meeting → 去哪里？→ 介词短语做状语
③ right now → 立刻马上 → 时间状语 ✓
④ 时间状语 → 需要变序 → 调到 go 前面

翻译结果

变序操作：
① 时间状语 right now → 变序（调 go 前面）

翻译：我们必须立刻马上去开会。

9. 五大例句完整总结表

例句 句型 关键成分 是否变序 翻译
It was a pity that you didn't watch that wonderful football match. SVP（主系表）+ 主语从句 第一个 that=引导词（主语从句）；第二个 that=指示代词（那个）；It=形式主语 不变序 很遗憾你没有看这场精彩的足球比赛。

You had better answer the question in English. SVO（主谓宾） had better+answer=谓语；in English=方式状语 方式状语变序 你最好用英语来回答这个问题。
Dishes that the Chinese all over the world are hoping for (the realization for modernization). SVO（主谓宾） that=关系代词；all over the world=后置定语；for modernization=后置定语 两个后置定语都变序 全世界的中国人都在期待希望着四个现代化的实现。

10. 核心知识点总结

知识点一：that 的三种身份辨析

判断维度 从属连词 关系代词 指示代词
that 后接 完整句子（主+谓） 完整句子（主+谓） 名词短语（无主谓）
that 做成分 不做成分 做主/宾/表 不做成分（修饰名词）
典型例句 It was a pity that you didn't come. The book that I bought... Watch that wonderful match.

知识点二：It 作形式主语的识别

判断方法 说明
去掉 It 去掉 It 后，主句缺主语 → It 是形式主语，真正主语在后面
常见真正主语 ① 不定式（to do）② 动名词（doing）③ that 从句
句型归属 主系表（SVP）→ 主干不变序

知识点三：主干完了的 to do → 优先考虑目的状语

位置 优先考虑 是否变序
主谓宾结构之后的 to do 目的状语（修饰动词） ✅ 不变序（动作之后）
判断方法 用中文辅助："做A的目的是B"是否通顺 ——

知识点四：had better 的谓语构成

结构 分析 例句
had better + 动词原形 had better 是助动词/情态动词类，+ 实义动词原形 = 一个谓语 You had better answer the question.
类似结构 would rather / might as well / used to 等 ——

知识点五：不及物动词 + 介词 = 谓语

结构 分析 例句
不及物动词 + 介词 不及物动词不能直接接宾语，必须加介词后才能接宾语 → 整体构成谓语 hope for / look at / listen to
本句应用 are hoping for = 谓语（hope 不及物 + for） ...are hoping for the realization...

知识点六：不定代词 + 后置定语

不定代词 特点 例句
something / anything / nothing / everything 非常笼统 → 后面跟后置定语的概率很大 something to help the comrades

12. 核心判断逻辑总结

G55 核心方法总结

第一步：找谓语动词 → 数个数 → 找连接词 → 判断句型类型
↓
第二步：看到 that 不要激动 → 看后面跟什么（主谓→引导词/关系代词；名词→指示代词）
↓
第三步：看到 It 开头 → 考虑是不是形式主语（去掉 It 看是否缺主语）
↓
第四步：主干完了的 to do → 优先考虑目的状语（不变序）
↓
第五步：不定代词（something等）→ 优先考虑后置定语（需要变序）
↓
第六步：had better / must / should 等 → 情态动词+实义动词=一个谓语
↓
第七步：不及物动词+介词=一个谓语（hope for / look at / listen to）
↓
第八步：变序操作 → 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前
核心口诀：
- 谓语动词是解开所有句子的钥匙
- 看到 that 不要激动，看后面跟主谓还是名词
- 看到 It 开头要想想是不是形式主语
- 主干完了的 to do → 优先考虑目的状语（不变序）
- 不定代词后面 → 优先考虑后置定语（需要变序）
- had better / must / should + 动词原形 = 一个谓语
- 不及物动词 + 介词 = 一个谓语（hope for / look at）
- 变序 = 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前

  1. 牢记 that 的三种身份：从属连词（that+主谓，不做成分）、关系代词（that+主谓，做成分）、指示代词（that+名词短语，"那个"）。看到 that 不要激动，先看后面跟什么。

  3. 牢记"主干完了的 to do → 优先考虑目的状语"：主谓宾结构之后的 to do，用中文辅助判断"做A的目的是B"是否通顺，通顺 → 目的状语（不变序）。
  4. 牢记不定代词 + 后置定语：something/anything/nothing/everything 非常笼统 → 后面跟后置定语的概率很大。
  5. 牢记 had better / must / should + 动词原形 = 一个谓语：情态动词/助动词类 + 实义动词原形 → 一起构成谓语。

  7. 翻译三步法：找谓语 → 识别句型 → 找后置定语和状语变序 → 翻译完成。每一步都不能跳过。
