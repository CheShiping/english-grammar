【G47】反义疑问句

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G47 是「基础语法」系列第47课，由陈老师主讲。本节课是句子部分的专题小课，紧接 G46「同位语从句 vs 定语从句」，专门讲解反义疑问句（Tag Question）的核心规则与特殊用法。

反义疑问句在初中阶段讲得比较多，但初中老师往往讲得很复杂。本节课从底层逻辑出发——居高临下地看这个句型，几分钟就能掌握所有要点。

本节课的核心目标：掌握反义疑问句的三步构成法（完整句子 + 逗号 + 助动词/系动词 + 人称代词），理解"前肯后否、前否后肯"的核心规则，以及 There be 句型、主语从句、祈使句三大特殊用法。
前置知识要求：
本节课建立在 G40「五大基本句型」、G42「祈使句」的基础上。需要熟练掌握动词分类（助动词/系动词/实意动词）、人称代词、五大基本句型等知识。

2. 反义疑问句的核心规则：前肯后否，前否后肯

老师首先点明反义疑问句的核心口诀——反着来：

主句语气 反义疑问部分
肯定 否定（前肯后否）
否定 肯定（前否后肯）
核心口诀：
- 反义 = 反着唱反调
- 前肯后否，前否后肯，总之反着来就对了

3. 反义疑问句的三步构成法

老师从结构上拆解反义疑问句的构成，分为三步：

步骤 内容 说明
第一步 一个完整的句子 不缺主、宾、表，即五大基本句型（SV / SVO / SVP / SVOOC / SVOIO）都算完整
第二步 加逗号 逗号后面只有两个词的位置
第三步 两个词：助动词/系动词 + 人称代词主语 第一个词是助动词或系动词（根据前句决定肯/否）；第二个词必须用人称代词
核心逻辑：逗号后面只有两个词的位置——第一个词给助动词/系动词，第二个词给人称代词主语。这就是反义疑问句的全部结构。

4. 第一步详解：什么是"完整的句子"

老师详细解释了"完整句子"的判断标准——不缺主、宾、表：

句型 例句 是否完整 分析
SV（主谓） Birds fly. ✅ 完整 不及物动词单独构成主谓，不缺成分
SVO（主谓宾） I like English. ✅ 完整 主语+及物动词+宾语，不缺成分
SVO（不完整） I like. ❌ 不完整 及物动词后面缺宾语，话没说完
SVP（主系表） It is sunny today. ✅ 完整 系动词+表语，不缺成分
SVP（不完整） It is. ❌ 不完整 系动词后面缺表语，话没说完
SVOOC（主谓宾宾补） I find it nice. ✅ 完整 主语+及物动词+宾语+宾补，不缺成分
SVOIO（主谓间宾直宾） She told me a joke. ✅ 完整 主语+及物动词+间宾+直宾，不缺成分
SVOIO（不完整） She told me. ❌ 不完整 VT2 双宾语动词缺直宾，话没说完
形容词性物主代词后 This is my... ❌ 不完整 形容词性物主代词（my/your/his）后面必须加名词
核心辨析：
- 判断完整与否的方法：读一下句子，看意思说完整了没有
- 形容词性物主代词（my/your/his/her/its/our/their）后面不能空着，必须加名词
- "This is my." 是错的，必须是 "This is my book."

5. 第三步详解：助动词/系动词的选取（核心难点）

这是本节课最重要的部分——逗号后面第一个词应该用什么：

规则一：句中有助动词或系动词 → 直接用

主句 分析 反义疑问部分
He can speak English. can 是助动词 → 直接用 前肯 → 后否 → can't he?
He is a good student. is 是系动词 → 直接用 前肯 → 后否 → isn't he?
Tom can speak English. can 是助动词；Tom → he 前肯 → 后否 → can't he?
Lily can speak English. can 是助动词；Lily → she 前肯 → 后否 → can't she?
Lily isn't a student. isn't 是系动词（已否定） 前否 → 后肯 → is she?

规则二：句中只有实意动词 → 抽象成 does/do/did

主句 分析 反义疑问部分
He speaks good English. speaks 是实意动词 → 抽象成 does（第三人称单数现在时） 前肯 → 后否 → doesn't he?
Tom speaks good English. speaks → does；Tom → he 前肯 → 后否 → doesn't he?
Lily speaks good English. speaks → does；Lily → she 前肯 → 后否 → doesn't she?
Lily won't speak English. won't 是助动词（已否定） 前否 → 后肯 → will she?
核心辨析：
- 实意动词（如 speaks/likes/goes）不能直接放在反义疑问部分
- 必须"抽象"成助动词：第三人称单数现在时 → does；第一/二人称现在时 → do；过去时 → did
- 口诀：实意动词不能直接用，要抽象成 does/do/did

6. 特殊考点一：否定副词（hardly）

老师讲解了一个重要的特殊情况——否定副词：

He can hardly speak English.
→ 句中有 hardly（几乎不），这是一个否定副词
→ 虽然 can 是肯定的，但 hardly 已经表示否定了
→ 前否 → 后肯 → can he?（不用 can't）
否定副词 含义
hardly 几乎不（表示否定）
never 从不（表示否定）
seldom 很少（表示否定）
rarely 很少（表示否定）
scarcely 几乎不（表示否定）
核心辨析：
- 含有 hardly/never/seldom 等否定副词的句子，虽然形式上是肯定的，但语义上是否定的
- 所以反义疑问部分要用肯定形式
- He can hardly speak English → can he?（不是 can't he!）

7. 特殊考点二：There be 句型

老师讲解 There be 句型的反义疑问句特殊规则：

There is a car, isn't there?
→ 主句：There is a car（完整句子 ✓）
→ is 是系动词 → 直接用
→ 前肯 → 后否 → 但主语不用 it，而用 there
→ 结果：isn't there?
核心逻辑：There be 句型中，there 不是主语，真正的主语是 be 后面的名词。但反义疑问部分不用名词的人称代词（如 it），而是固定用 there。这是 There be 句型的特殊规则。
There are many students in the classroom, aren't there?
→ are 是系动词 → 直接用；前肯 → 后否 → aren't there?

8. 特殊考点三：主语从句 → 用 it 代替

老师讲解当主句的主语是一个从句时（主语从句），反义疑问部分用 it 代替整个从句：

What he said is right, isn't it?
→ 主句：What he said is right
→ 主语是 What he said（主语从句），是一个句子做主语
→ 一个句子的主语 → 用 it 代替
→ is 是系动词 → 前肯 → 后否 → isn't it?
核心辨析：
- 当主语是一个从句（如 What he said / What you want / Where he goes）时，反义疑问部分用 it
- 不能说 "isn't what he said?"（太长了，像说相声）
- 原理：一个句子做主语 → 用 it 代替

9. 特殊考点四：祈使句

老师讲解祈使句的反义疑问句特殊规则：

Shut up, will you?
→ 祈使句省略了主语 you（You shut up）
→ 祈使句天然表将来 → 助动词用 will
→ 省略的主语是 you → 用 you
→ 结果：will you?（肯定否定都可以，语气略有不同）
祈使句类型 反义疑问部分 例句
一般祈使句 will you? / won't you? Shut up, will you? / Open the door, won't you?
Let's 开头 will we? Let's go, will we?
核心逻辑：祈使句省略了主语 you，天然表将来（用 will）。所以反义疑问部分用 will you。Let's 开头隐含省略的是 we（第一人称），所以用 will we。

10. 人称代词选取规则

老师强调反义疑问部分的第二个词必须用人称代词：

主句主语 反义疑问部分主语 原因
He / Tom / 男生名字 he 人名 → 对应的人称代词
She / Lily / 女生名字 she 人名 → 对应的人称代词
It / 事物 it 事物 → it
I I 第一人称 → I
You you 第二人称 → you
We we 第一人称复数 → we
They they 第三人称复数 → they
一个句子（主语从句） it 一个句子做主语 → 用 it 代替
There be 句型 there There be 句型特殊规则
核心辨析：
- 不能说 "isn't Tom?" / "isn't New York?" / "isn't the man who is wearing a hat?"
- 必须用人称代词：Tom → he, New York → it, 一个句子 → it
- There be 句型特殊：用 there 代替

11. 完整实战演练

老师用多个例句完整演示反义疑问句的构建过程：

例句一：He can speak English.

第一步：完整句子？→ He can speak English（主谓宾完整 ✓）
第二步：打逗号 → He can speak English, ____ ____?
第三步：can 是助动词 → 直接用；前肯 → 后否 → can't he?
结果：He can speak English, can't he?

例句二：He is a good student.

第一步：完整句子？→ It is sunny today（主系表完整 ✓）
第二步：打逗号 → He is a good student, ____ ____?
第三步：is 是系动词 → 直接用；前肯 → 后否 → isn't he?
结果：He is a good student, isn't he?

例句三：He speaks good English.

第一步：完整句子？→ He speaks good English（主谓宾完整 ✓）
第二步：打逗号 → He speaks good English, ____ ____?
第三步：speaks 是实意动词 → 抽象成 does；前肯 → 后否 → doesn't he?
结果：He speaks good English, doesn't he?

例句四：He can hardly speak English.

第一步：完整句子？→ He can hardly speak English（主谓宾完整 ✓）
第二步：打逗号 → He can hardly speak English, ____ ____?
第三步：can 是助动词 → 直接用；但 hardly 是否定副词 → 前否 → 后肯 → can he?
结果：He can hardly speak English, can he?

例句五：There is a car, ___ ___?

第一步：完整句子？→ There is a car（完整 ✓）
第二步：打逗号 → There is a car, ____ ____?
第三步：is 是系动词 → 直接用；There be 句型特殊 → 用 there；前肯 → 后否 → isn't there?
结果：There is a car, isn't there?

例句六：What he said is right, ___ ___?

第一步：完整句子？→ What he said is right（主系表完整 ✓）
第二步：打逗号 → What he said is right, ____ ____?
第三步：is 是系动词 → 直接用；主语是 What he said（从句）→ 用 it；前肯 → 后否 → isn't it?
结果：What he said is right, isn't it?

例句七：Shut up, ___ ___?

第一步：完整句子？→ Shut up = You shut up（祈使句，省略主语 you ✓）
第二步：打逗号 → Shut up, ____ ____?
第三步：祈使句天然表将来 → will；省略的主语是 you → you；will you? / won't you?
结果：Shut up, will you? / won't you?

例句八：Let's go, ___ ___?

第一步：完整句子？→ Let's go = Let us go（祈使句，隐含主语 we ✓）
第二步：打逗号 → Let's go, ____ ____?
第三步：Let's 隐含主语是 we → will we?
结果：Let's go, will we?

12. 三大特殊用法总结表

特殊句型 反义疑问部分 原因 典型例句
There be 句型 isn't/aren't + there There be 句型特殊规则，不用 it There is a car, isn't there?
主语从句 isn't/doesn't + it 一个句子做主语 → 用 it 代替 What he said is right, isn't it?
祈使句（一般） will you? / won't you? 祈使句省略 you + 天然表将来（will） Shut up, will you?
祈使句（Let's） will we? Let's 隐含主语是 we Let's go, will we?

13. 助动词/系动词选取速查表

前句动词类型 反义疑问部分动词 例句
有助动词（can/will/should/may/must...） 直接用该助动词（肯/否反着来） He can swim, can't he?
有系动词（am/is/are/was/were） 直接用该系动词（肯/否反着来） She is a teacher, isn't she?
只有实意动词（现在时） 抽象成 does（三单）/ do（其他） He speaks English, doesn't he?
只有实意动词（过去时） 抽象成 did He spoke English, didn't he?
有 have（表示"有"） 直接用 have/has（英式）/ do（美式） He has a car, hasn't he? / doesn't he?

14. 核心判断逻辑总结

老师总结了判断反义疑问句的核心逻辑：

第一步：看主句是否完整 → 不缺主宾表？→ 继续
第二步：打逗号，看前句有助动词/系动词吗？
 有 → 直接用（肯/否反着来）
 没有 → 实意动词抽象成 does/do/did
第三步：主语用人称代词（There be → there；主语从句 → it；祈使句 → you/we）

反义疑问句判断三步法

步骤 操作
第一步 确认主句完整（不缺主/宾/表）→ 不完整则不能构成反义疑问句
第二步 看前句动词：有助动词/系动词 → 直接用；只有实意动词 → 抽象成 does/do/did；注意否定副词（hardly/never）→ 前否后肯
第三步 主语用人称代词：一般人名 → he/she/it；There be → there；主语从句 → it；祈使句 → you/we
核心口诀：
- 前肯后否，前否后肯（反着来）
- 有助动词/系动词 → 直接用；只有实意动词 → 抽象成 does/do/did
- 主语必须用人称代词（不用人名、不用名词）
- 特殊：There be → there；主语从句 → it；祈使句 → will you/won't you / Let's → will we
- 注意否定副词：hardly/never/seldom → 语义否定 → 后肯

15. 课程总结思维导图

🎓 学习建议总结

  1. 牢记三步构成法：完整句子 + 逗号 + 助动词/系动词 + 人称代词。这是反义疑问句的全部结构。
  2. 助动词选取是核心难点：有助动词/系动词 → 直接用；只有实意动词 → 抽象成 does/do/did。这是最容易出错的地方。
  3. 注意否定副词：hardly/never/seldom/rarely/scarcely 表示否定语义 → 前否后肯 → 反义疑问部分用肯定形式。
  4. 人称代词必须用：不能用人名或名词重复，必须用人称代词（he/she/it/it/there/you/we）。
  5. 三大特殊用法必须记住：There be → there；主语从句 → it；祈使句 → will you / Let's → will we。
  6. 判断完整与否：读一下句子，看意思说完整了没有。形容词性物主代词（my/your/his）后面必须加名词。
