【G60】长难句3（为什么你分析长难句总是要出错？）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G60 是「基础语法」系列第60课，由陈老师主讲。本节课是句子部分的长难句实战分析课（续），紧接 G59「长难句分析（2）」。本节课聚焦一个核心问题——为什么你分析长难句总是要出错？，通过两个典型例句揭示最常见的错误根源，并引入本节课最重要的方法论。

本节课重点讲解两个高频易错考点：① AABB型动词的50%判断法（made/built等过去式/过去分词同形，需判断是谓语还是非谓语）以及② 英语第一原则"一山不容二虎"（一个主语只能带一个谓语，出现第二个谓语必须用非谓语形式），同时强化后置定语的识别、同位语的判断等核心技能。

本节课的核心目标：通过2个经典例句的逐句深度分析，掌握AABB型动词的50%判断法、"一山不容二虎"原则在长难句分析中的应用，彻底解决"多找谓语"这一最常见错误。
前置知识要求：
本节课建立在 G40「五大基本句型」、G43「从句/复合句1.0」、G52「翻译公式」、G53-G59「句子成分分析及翻译/长难句分析」的基础上。需要熟练掌握谓语动词识别、非谓语动词（to do/doing/done）、后置定语、同位语等知识。

2. 核心易错点一：AABB型动词的50%判断法

老师以一个经典例句切入，揭示了同学们最容易犯的错误——把非谓语动词误判为谓语动词：

It is hoped that the report made by Mr. Chen the engineer will stimulate the students' interest in electronic computer.
→ 初看有三个"谓语"：is hoped（谓语1）、made（？）、will stimulate（谓语3）
→ 三个谓语 → 按理说应该有两个连接词，但只找到了一个 that → 矛盾！
→ 矛盾说明：要么连接词被省略了，要么多找了一个谓语动词
核心口诀：
- 看到 is + 过去分词 → 100% 是被动语态（谓语）
- 看到 AABB型动词（如 made/built）→ 只有50% 是谓语，需要进一步判断
- made 的原型是 make，过去式是 made，过去分词也是 made（AABB型）
- made 既可以抽象成 did（谓语），也可以抽象成 done（非谓语/后置定语）

如何判断 made 是谓语还是非谓语？

判断方法 操作 本句应用
主动/被动判断 看名词和动词的主动/被动关系 the report 和 make → 报告是"被陈先生做的" → 被动 → done形式 → 非谓语 ✓
后置定语检验 看名词短语是否被缩小范围 the report（很大/笼统）→ made by Mr. Chen（把它变小了）→ 后置定语 ✓
一山不容二虎 一个主语只能有一个谓语 主语 it 已经有 is hoped 做谓语 → made 不能再做谓语 → 必须是非谓语 ✓

3. 核心易错点二：英语第一原则"一山不容二虎"

老师强调，同学们分析句子总出错的根本原因——永远不考虑"一山不容二虎"原则：

一山不容二虎 = 一个主语，只能带一个谓语
→ 如果你想再出现谓语动词，必须用非谓语形式（to do / doing / done）
→ 判断方法：看主语后面有没有谓语了 → 有谓语 → 后面的动词必须是非谓语
→ 标志：中间没有连接词 → 说明是非谓语（后置定语/状语等）
核心逻辑：
- 英语的第一原则：一山不容二虎（一个主语只能有一个谓语）
- 看到 made/built 等 AABB型动词 → 不要激动 → 先看主语后面有没有谓语了
- 有谓语 + 中间无连接词 → 必须是非谓语（done 表被动）
- by 是被动的重要标志词

4. 例句一：It is hoped that the report made by Mr. Chen the engineer will stimulate the students' interest in electronic computer.

分析过程：
① 找谓语：is hoped（谓语1，is+过去分词=被动语态）+ will stimulate（谓语2，will+stimulate原形）→ 两个谓语
② made 不是谓语！→ made 是 AABB型动词，只有50%可能性 → 主动/被动判断 → 报告是被做的 → done → 非谓语 → 后置定语
③ 连接词个数 = V - 1 = 2 - 1 = 1 → that 是从属连词，从 that 处划开
④ 主句：It is hoped（It 开头 + 被动及完整 → It 是形式主语，真正主语是 that 从句）
⑤ 从句：that the report made by Mr. Chen the engineer will stimulate the students' interest in electronic computer

从句内部精细分析

that the report made by Mr. Chen the engineer will stimulate the students' interest in electronic computer
→ that 在从句中不做成分（引导词）
→ the report made by Mr. Chen the engineer = 从句主语（the report 是中心词，made by Mr. Chen 是后置定语）
→ Mr. Chen the engineer = 同位语（陈先生就是工程师 → 1:1等同 → 同位语）
→ will stimulate = 从句谓语
→ the students' interest = 宾语
→ in electronic computer = 后置定语，修饰 interest（"电子计算机方面的兴趣"）→ 缩小范围
核心辨析——Mr. Chen the engineer 是同位语：
- 陈先生 = 工程师 → 1:1等同 → 同位语
- 同位语 = 对前面名词的补充说明，两者是同一事物
- 类似：my friend the doctor（我的朋友，那个医生）

翻译结果

变序操作：
① 主语从句（It 形式主语）→ 不变序
② 后置定语 made by Mr. Chen → 变序（调 report 前面）
③ 同位语 Mr. Chen the engineer → 变序（调 Mr. Chen 前面，也可以不变）
④ 后置定语 in electronic computer → 变序（调 interest 前面）

直译：被希望的是，由工程师陈先生所做的报告将会激发学生们在电子计算机方面的兴趣。
符合中文习惯：大家希望，工程师陈先生所做的报告将会激发学生们对电子计算机方面的兴趣。

5. 例句二（高考真题）：The adobe dwelling built by the Pueblo Indians of the American Southwest...

分析过程：
① 找谓语：built（？，AABB型动词，只有50%可能性）+ are（谓语，be动词）→ 两个谓语
② built 是 build 的过去式和过去分词（AABB型）→ 需要判断是谓语还是非谓语
③ 主动/被动判断：the adobe dwelling（土坯房）和 build → 土坯房是被建的 → 被动 → done → 非谓语 ✓
④ 一山不容二虎：主语 the adobe dwelling 后面有 are（谓语）→ built 不能再做谓语 → 必须是非谓语 → 后置定语 ✓
⑤ 标志词 by → 被动的重要标志

完整句子分析

The adobe dwelling built by the Pueblo Indians of the American Southwest are admired by even the most modern architects and engineers.
→ 主语：the adobe dwelling（土坯房）
→ 后置定语：built by the Pueblo Indians（由普韦布洛印第安人建造的）
→ 后置定语：of the American Southwest（美国西南部的）→ 修饰 Pueblo Indians → 缩小范围
→ 谓语：are admired（被动语态）
→ 方式状语：by even the most modern architects and engineers（被最现代的建筑师和工程师所崇拜）
核心辨析——built 为什么不是谓语：
- 很多同学看到 build → built（过去式/过去分词）→ 很兴奋 → 直接画谓语 → 错了！
- 判断方法1（主动/被动）：土坯房是被建的 → 被动 → done → 非谓语
- 判断方法2（一山不容二虎）：主语 the adobe dwelling 后面有 are（谓语）→ built 不能做谓语
- 判断方法3（by标志）：built 后面有 by → 被动标志 → done → 非谓语
- 中间没有连接词 → 说明 built 是非谓语（后置定语）

翻译结果

变序操作：
① 后置定语 built by the Pueblo Indians → 变序（调 dwelling 前面）
② 后置定语 of the American Southwest → 变序（调 Pueblo Indians 前面）
③ 方式状语 by even the most modern architects and engineers → 变序（调 admired 前面）

翻译：由美国西南部的普韦布洛印第安人所建造的土坯房，被最现代的建筑师和工程师所崇拜。

7. 核心知识点总结

知识点一：AABB型动词的50%判断法

判断维度 说明
什么是AABB型 过去式和过去分词同形的动词（如 make-made-made / build-built-built）
50%含义 made/built 既可以抽象成 did（谓语，主动语态）→ 也可以抽象成 done（非谓语，被动语态）
判断方法1 主动/被动判断：名词和动词是主动还是被动关系？被动 → done → 非谓语
判断方法2 一山不容二虎：主语后面已有谓语 → 不能再用谓语 → 必须是非谓语
判断方法3 by标志：后面有 by → 被动标志 → done → 非谓语
后置定语检验 看名词是否被缩小范围 → 是 → 后置定语 → 非谓语

知识点二：英语第一原则"一山不容二虎"

原则 说明
核心内容 一个主语，只能带一个谓语
后果 如果你想再出现谓语动词，必须用非谓语形式（to do / doing / done）
判断方法 看主语后面有没有谓语了 → 有谓语 + 中间无连接词 → 后面的动词必须是非谓语
常见错误 很多同学看到 made/built 就很激动，直接画谓语 → 忽略了"一山不容二虎"→ 出错
标志词 by（被动标志）、中间无连接词（说明是非谓语）

知识点三：同位语的识别

判断维度 说明
核心特征 1:1等同关系 → A就是B，B就是A
本句应用 Mr. Chen = the engineer（陈先生就是工程师）→ 1:1等同 → 同位语
翻译方式 可以翻译成"工程师陈先生"（变序）或保持原序

知识点四：is hoped 的被动及完整

判断维度 说明
结构 is + hoped（过去分词）→ 被动语态
及物性 hope 是及物动词，但变为被动后，宾语已提前为主语 → 后面不缺宾语 → 不是宾从
It 形式主语 It is hoped that... → It 代指 that 从句 → It 是形式主语，that 从句是真正主语（主语从句）
类似结构 It is said that / It is believed that / It is reported that / It is hoped that...

知识点五：非谓语做后置定语的三种形式

非谓语形式 含义 本句应用
to do 表将来、表目的 ——
doing 表主动、表进行 ——
done 表被动、表完成 made by Mr. Chen（被陈先生做的）；built by the Pueblo Indians（被印第安人建造的）

8. 变序/不变序速查总结

成分 例句中的位置 是否变序 调到
主语从句（It 形式主语） that the report made by...（做 is hoped 的真正主语） ✅ 不变序 ——
后置定语（done） made by Mr. Chen（修饰 report） 需要变序 调到 report 前面
同位语 Mr. Chen the engineer（= 陈先生就是工程师） 可不变序（灵活处理） ——
后置定语（in短语） in electronic computer（修饰 interest） 需要变序 调到 interest 前面
后置定语（done） built by the Pueblo Indians（修饰 dwelling） 需要变序 调到 dwelling 前面
后置定语（of短语） of the American Southwest（修饰 Pueblo Indians） 需要变序 调到 Pueblo Indians 前面

9. 核心判断逻辑总结

G60 核心方法总结

第一步：找谓语动词 → 数个数 → 找连接词 → 判断句型类型
↓
第二步：看到 is + 过去分词 → 100% 被动语态（谓语）
↓
第三步：看到 AABB型动词（made/built）→ 只有50%是谓语 → 需要判断
 方法1：主动/被动判断 → 被动 → done → 非谓语

↓
第五步：后置定语 → 调名词前面；同位语 → 灵活处理
↓
第六步：变序操作 → 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前
核心口诀：
- 谓语动词是解开所有句子的钥匙
- is + 过去分词 → 100% 被动（谓语）
- made/built → 50% 是谓语 → 用三种方法判断（主动被动/一山不容二虎/by标志）

- 有谓语 + 中间无连接词 → 后面的动词必须是非谓语（to do/doing/done）
- by 是被动的重要标志词
- Mr. Chen the engineer → 1:1等同 → 同位语
- It is hoped that... → It 形式主语 + 主语从句（类似 It is said/believed/reported that...）
- 变序 = 后置定语调名词前 + 状语（除目的/结果/伴随）调动词前

🎓 学习建议总结

  1. 牢记AABB型动词的50%判断法：made/built 等过去式和过去分词同形的动词，只有50%可能性是谓语。用三种方法判断：①主动/被动判断 ②一山不容二虎 ③by标志。
  2. 牢记英语第一原则"一山不容二虎"：一个主语只能带一个谓语。如果你想再出现动词，必须用非谓语形式（to do/doing/done）。很多同学出错就是因为永远不考虑这个原则。
  3. 牢记 is + 过去分词 = 100% 被动语态：is hoped / is reported / is said / is believed → 被动及完整 → 不是宾从。It + 被动 + that从句 → It 是形式主语，that从句是真正主语（主语从句）。
  4. 牢记 by 是被动的重要标志词：看到 by + 名词 → 很可能前面是 done 做后置定语（被动）。
  5. 牢记同位语的识别：1:1等同关系 → A就是B，B就是A → 同位语。Mr. Chen the engineer（陈先生就是工程师）。
  6. 牢记非谓语做后置定语的三种形式：to do（表将来/目的）/ doing（表主动/进行）/ done（表被动/完成）。made by / built by 都是 done 形式 → 后置定语。
  7. 翻译灵活处理：同位语可以变序也可以不变序（如"工程师陈先生"比"陈先生工程师"更自然）。符合中文习惯是终极标准。
