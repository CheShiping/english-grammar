【G51】高级语法之省略（你一直以为是固定搭配）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G51 是「基础语法」系列第51课，由陈老师主讲。本节课是句子部分的高级语法专题课，紧接 G50「Where引导的六种从句」，专门讲解省略（Ellipsis）的核心原理及其在英语中的实际应用。

老师以 "I don't know"（后面没有宾语）这个同学们长期困惑的现象为切入点——know 是及物动词，按理说后面必须接宾语，但口语中却可以说 "Sorry, I don't know." 为什么？答案就是：这是一种省略。

本节课的核心目标：理解省略的两个条件（重复 + 不产生歧义），掌握省略的核心理念（不产生歧义是交流的最关键因素），并通过实战理解"你一直以为是固定搭配"的表达其实是省略+非谓语变化的结果。
前置知识要求：
本节课建立在 G40「五大基本句型」、G43「从句/复合句1.0」、G44「从句2.0」的基础上。需要熟练掌握及物动词、宾语从句、引导词做成分、非谓语动词（to do/doing/done）等知识。

2. 省略的两个条件

老师总结省略必须同时满足两个条件：

条件 核心含义 说明
重复 某些内容在上下文中已经出现过 如果前后没有重复的内容，就没有省略的对象
不产生歧义 省略后不会影响理解 这是最重要的条件！语言是用来交流的，根本原则是不产生歧义
核心辨析：
- 两个条件中，不产生歧义是最重要的
- 因为语言的根本目的是交流，只要不产生歧义，即使没有重复也可以省略（如用手势、眼神）
- 不产生歧义 > 重复

3. 省略的核心理念：不产生歧义

老师强调"不产生歧义"是交流的最关键因素，并用生动例子说明：

案例一：没有重复也可以省略

场景1：老师用手比划"闭嘴"的手势 → 不需要说话，对方就懂了 → 省略了"Shut up!"
场景2：一个眼神 → 传达了爱意 → 省略了"I love you"
场景3：《肖申克救赎》中"时间到了" → 只说"Time." → 省略了"is up/over"
场景4：看手表位置 → 问"几点了" → 对方懂了 → 省略了完整问句
核心逻辑：语言是用来交流的。只要不产生歧义，即使没有重复，也可以通过手势、眼神、上下文等省略内容。不产生歧义是交流的最关键因素。

4. 实战一：I don't know 的省略真相

老师以 "I don't know" 为例，揭示省略的完整过程：

完整形式 → 省略形式

步骤 内容 分析
完整形式 I don't know her WeChat. know 是及物动词，后面必须接宾语 her WeChat
对话上下文 A: Do you know her WeChat? B: I don't know (her WeChat). her WeChat 在上下文中重复了
省略 I don't know (her WeChat). 省略重复的 her WeChat，意思不变，不产生歧义 ✓
核心辨析：
- "I don't know" 不是固定搭配，而是省略了宾语的完整句子
- 省略后不会理解为"我不知道那些仓皇南飞的大雁，究竟带走了谁的思念"→ 不产生歧义 ✓
- know 是及物动词（能接宾语就证明了），口语中省略宾语是因为重复+不产生歧义

5. 实战二：I don't know what I should do → I don't know what to do

老师用宾语从句的完整分析，揭示 "what to do" 的真正来源：

完整从句分析

分析维度 内容 说明
主句 I don't know I=主语，don't know=谓语（know是及物动词）
从句 what I should do what=引导词（做do的宾语，提到句首举牌子），I=主语，should do=谓语
为什么用 what 不用 how do 是及物动词，缺宾语 → 必须用能做宾语的词 → what（代词/名词性）可以做宾语 how 是副词，不能做宾语 → 所以 how 后面必须加 it 做宾语

省略过程（核心！）

步骤 内容 分析
发现重复 I don't know what I should do → 主句主语 I 和从句主语 I 重复了 两个 I 是同一个主语
省略主语 I I don't know what ___ should do 省略重复的主语 I
关键问题 主语没了，还能用谓语形式吗？ 有主语才能接谓语 → 主语没了，不能用谓语形式！
改为非谓语 should do → to do 非谓语有三种：to do / doing / done。情态动词 should 表主观意愿（不确定），与 to do 的本质（不确定）一致 → 变成 to do
最终结果 I don't know what to do. 不是固定搭配！是省略+非谓语变化的逻辑结果！
核心口诀：
- 主语重复 → 省略主语 → 没有主语就不能用谓语 → 必须改成非谓语
- 情态动词（should/can/must）表主观意愿 = 不确定 → 对应 to do（本质也是不确定）
- 所以 should do → to do
- "I don't know what to do" 不是固定搭配，是省略+非谓语的逻辑结果！

6. 实战三：I don't know how I should do it → I don't know how to do it

老师用同样逻辑分析 how 引导的版本：

为什么 how 后面要加 it？

对比项 what I should do how I should do it
引导词词性 what = 代词/名词性 how = 副词
do 缺不缺宾语 do 缺宾语 → what 做宾语 ✓ do 缺宾语 → how 是副词不能做宾语 ✗ → 需要 it 做宾语
完整形式 I don't know what I should do. I don't know how I should do it.
省略后 I don't know what to do. I don't know how to do it.

省略过程

完整：I don't know how I should do it.
→ 主句主语 I 和从句主语 I 重复 → 省略从句主语 I
→ 没有主语了 → should do 不能保持谓语形式 → 改成非谓语 to do
结果：I don't know how to do it.
核心辨析：
- what to do：what 本身可以做 do 的宾语，所以不需要 it
- how to do it：how 是副词，不能做宾语，do 的宾语必须由 it 承担
- 这不是固定搭配！是引导词词性 + 省略 + 非谓语变化的逻辑结果！

7. 非谓语动词本质回顾

老师回顾了非谓语动词的三种形式及其本质，以解释为什么 should do → to do：

非谓语形式 本质 说明
to do 不确定 表将来、表目的、表意愿。情态动词（should/can/must）也表主观意愿（不确定），所以 should do → to do
doing 确定/长期/同步 表正在进行的动作或与谓语同步发生的动作（如省略主动/进行时等）
done 被动/完成 表被动或完成的动作（如省略被动语态等）
核心逻辑链：
- 情态动词 should/can/must → 表达主观意愿 → 主观意愿 = 不确定
- to do 的本质 = 不确定
- 所以 should do → to do（不是固定搭配，是本质一致的必然结果）

8. 省略 vs 固定搭配：核心辨析

老师强调，很多同学们认为的"固定搭配"，其实是省略+语法变化的结果：

你以为的"固定搭配" 实际本质 推导过程
I don't know. 省略宾语 I don't know (her WeChat). → 重复+不产生歧义 → 省略宾语
I don't know what to do. 宾语从句 + 省略主语 + 非谓语 I don't know what I should do → 省略I → should do→to do
I don't know how to do it. 宾语从句 + 省略主语 + 非谓语 I don't know how I should do it → 省略I → should do→to do（it保留做宾语）
核心观点：
- 你一直以为是固定搭配的东西，其实背后都有语法逻辑
- 不是死记硬背"what to do"是固定搭配，而是理解：引导词what做宾语 + 主语I重复省略 + should do变非谓语to do
- 理解了背后的逻辑，就再也不用死记硬背了

9. 省略判断流程总结

老师总结了判断和使用省略的完整流程：

省略判断三步法

第一步：找重复 → 上下文中是否有重复的内容？
↓
第二步：看歧义 → 省略后会不会产生歧义？
 不产生歧义 → 可以省略 ✓
 产生歧义 → 不能省略 ✗
↓
第三步：省略后调整 → 如果省略了主语，谓语要改成非谓语形式

省略三步法

步骤 操作
第一步 找重复：上下文中是否有重复的内容（主语/宾语等）
第二步 看歧义：省略后是否影响理解？不产生歧义 → 可以省略
第三步 省略后调整：如果省略了主语 → 原谓语必须改成非谓语（to do/doing/done）
核心口诀：
- 省略两个条件：重复 + 不产生歧义
- 不产生歧义是最重要的（语言是用来交流的）
- 省略主语 → 没有主语就不能用谓语 → 必须改非谓语
- 情态动词（表不确定）→ to do；doing（表确定/同步）；done（表被动/完成）
- 你以为是固定搭配，其实是省略+非谓语的逻辑结果！

🎓 学习建议总结

  1. 牢记省略两个条件：重复 + 不产生歧义。其中"不产生歧义"是最重要的，因为语言的根本目的是交流。
  2. 理解"I don't know"的本质：不是固定搭配，而是省略了宾语（如 her WeChat）。know 是及物动词，口语中因重复+不产生歧义而省略宾语。
  3. 掌握"what to do"的推导：完整形式 I don't know what I should do → 主语I重复省略 → 没有主语就不能用谓语 → should do 变成非谓语 to do（情态动词表不确定，与 to do 的不确定本质一致）。
  4. 掌握"how to do it"中 it 的必要性：how 是副词，不能做 do 的宾语，所以 it 必须保留。what to do 不需要 it，因为 what 本身可以做宾语。
  5. 非谓语本质：to do = 不确定（情态动词→to do）；doing = 确定/同步；done = 被动/完成。这是选择非谓语形式的关键。
  6. 不要死记固定搭配：很多你以为的固定搭配，背后都有语法逻辑。理解逻辑后就不用死记硬背了。
