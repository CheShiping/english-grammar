G06 基础语法 陈老师系列

【G06】other系列基础语法特供版

来源：Morty教谭警官学英语 | 整理与注释版

1. 课程背景与引入

G06「other系列」是「易筋经底层语法合集」P9位置的一节补充课程，由Morty老师主讲。原视频（2021年5月3日发布的"other全家桶"）因为语速快、内容凝练，导致很多从2018年开始学初级语法的萌新小白听起来非常痛苦，"头都听大了"。

因此，Morty老师重新录制了这个"初级语法特供版"，放慢语速、从基础角度讲解，让还在语法入门阶段的同学也能听懂。录完后会放到P9前面，原视频顺延到P10。

本节课的目标是：从初级语法的角度，彻底讲清楚 other 系列所有词的用法区别，让你以后再也不混淆。
前置知识要求：
必须理解 G01「名词短语」的概念！
- 名词短语 = 限定词 + 修饰词 + 主体词
- other 本身就是限定词（也可以认为是形容词）
- 限定词不能单独使用，后面必须加名词构成名词短语

2. 核心前提：other 的词性与基本规则

other 是一个限定词（也可以理解为形容词），它的核心规则是：

other + 可数名词复数 = others
✅ other students = others（其他学生）
✅ other people = others（其他人）
✅ other books = others（其他书）
这是理解 other 系列的"总开关"。other 后面必须加名词，当它加可数名词复数时，就等于 others。所以 others 本质上就是 other + 可数名词复数的合并形式。
名词的三种分类：
- 可数名词单数（C单）→ other 不能直接加
- 不可数名词（U）→ other 不能直接加
- 可数名词复数（C复）→ other 可以加，等于 others

3. 七大考点详解

考点一：other 不能单独使用

other 是限定词，后面必须加名词，不能单独放在句子末尾。

❌ I have other.（错误！other 后面没有名词）
✅ I have others.（正确！others = other + 可数名词复数）
✅ I have other plans.（正确！other + 可数名词复数 plans）
核心判断方法：
看到 other → 看后面有没有名词 → 没有名词就是错的！
想表达"我有其他的"→ 用 others（因为它自带名词含义）
想表达"我有其他XX"→ 用 other + 名词

4. 考点二：others 后面不能再加名词

既然 others = other + 可数名词复数，那么 others 本身就包含了名词的含义，后面不能再加名词。

❌ I have others plans.（错误！）
→ 解析：others = other plans，所以这句话等于 I have other plans plans（plans 重复了！）
✅ I have other plans.（正确！）
✅ I have others.（正确！）
一句话总结：
other + 名词 ✅ / others ✅ / other + 名词 + s ❌ / others + 名词 ❌
other 和 others 只能选一个，不能同时出现！

5. 考点三：other + 可数名词单数 / 不可数名词

other 正常情况下只加可数名词复数。如果想加可数名词单数或不可数名词，other 前面必须有修饰词（如 no / any / every）。

✅ There's no other way to say goodbye.（没有其他方式说再见。）→ no + other + 单数名词 way
这是 Air Supply 乐队歌曲 Goodbye 中的歌词。no 修饰 other，other 修饰 way（可数名词单数），结构完整。如果没有 no，直接说 "There's other way" 就是错的。
核心规则：
- other + 可数名词复数 → 不需要前面加东西（other students ✅）
- other + 可数名词单数 → other 前面必须有 no/any/every 等词（no other way ✅）
- other + 不可数名词 → other 前面必须有 no/any/every 等词

6. 考点四：others 与 some 搭配 → 泛指（泛指"其他的人/事/物"）

这是 other 系列最重要的用法之一。当说"一些人……另外一些人……"时，用 some... others... 搭配。

✅ Some students like basketball. Other students like football.（一些同学喜欢篮球，其他同学喜欢足球。）
→ other students 重复了 → 用 others 替代 → Some students like basketball. Others like football.
这里的 others 是泛指——世界上除了喜欢篮球的人，还喜欢足球、乒乓球、排球……各种各样的人都有，没有明确的总数范围。只要找到"另外一些人"就可以了。
✅ Some singers like pop music. Others like rock.（一些歌手喜欢流行音乐，其他歌手喜欢摇滚。）
→ 除了喜欢流行的歌手，还可以有喜欢乡村的、电音的、重金属的……没有总数限制。
泛指 = 没有总范围：
some... others... = "一些……其他的……"
其他人/事/物没有总数限制，还可以有"第三批""第四批"……
others 后面不加名词（因为 others 已经包含了名词含义）。

7. 考点五：the others → 特指（特指"剩余的全部"）

the others 与 others 的区别在于：有明确的总范围，指"除去一部分后，剩余的全部"。

✅ 班上60个人，20个女生 → the others（剩余的40个全部是男生）
→ 总范围是60人，除去20个女生，剩余的全部 = the others
✅ 买了10个包子，吃了3个 → the others（剩下的7个全被他吃了）
→ 总范围是10个包子，除去吃了的3个，剩余的全部 = the others
泛指 vs 特指 核心区别：
- others（泛指）→ 没有总范围，"另外一些人"，还可以有第三批、第四批
- the others（特指）→ 有总范围，"剩余的全部"，没有第三批了
the 的作用就是"限定"——把范围框死了！
✅ 和尚班60个人，1个女生 → the others（剩余的59个全部是男生）
→ 即使只除去1个，剩余的"全部"仍然用 the others

8. 考点六：the other → 两者的另一个

the other 后面接单数名词，表示两个中的另一个。总范围固定为2。

✅ One is a date palm. The other is a枣树.（一个是椰枣树，另一个是枣树。）
→ 总数是两个 → one... the other...

两种情况：

情况一：天生两个（身体部位等）

✅ 人天生有两条腿、两只手、两只耳朵 → the other leg/hand/ear
✅ 河天生有两条边（这边和那边）→ the other bank
✅ 街道天生有两条边 → the other side

情况二：明确告诉你有两个

✅ 我家门前有两棵枣树 → One is... The other is...
✅ 他有两个儿子 → One is... The other is...
one... the other... 固定搭配：
总数 = 2 时，"一个……另一个……"
one 指"其中一个"，the other 指"剩下的那个"（唯一的另一个）
注意：这里用 the other（单数），不是 the others（复数）！

9. 考点七：another → 在原先的基础上再多一个

another = an + other，表示"另一个"，核心含义是在原先的基础上再多一个出来。

✅ 你吃了3个小笼包，没吃饱 → another（再来一个）
✅ 你玩21点，已经拿了很多张牌 → another three（再来三张）
another 的核心逻辑：原先有几个不重要（可以是一个、两个、三个……），在原先的基础上"再来一个/再来一组"。你吃小笼包，吃了多少个不重要，没吃饱就说"再来一个"（another）。你玩21点，原来几张小牌不重要，说"再来一张"就是 another。
another 的"单位"概念：
another 后面的"一个"不一定是"一个"，可以是"一组/一段时间"等任意单位。
✅ Give me another five minutes.（再给我5分钟。）→ 单位是"5分钟"
✅ I'll pay you another three hundred dollars.（我再给你300美元。）→ 单位是"300美元"
原先已经给了多少个/多少单位不重要，"再来一个单位"就是 another。

10. 七大考点总览表

考点 形式 含义 关键特征
考点一 other + 名词 其他的…… other 是限定词，后面必须加名词，不能单独用
考点二 others（不加名词） 其他的人/事/物 others = other + 可数名词复数，后面不能再加名词
考点三 no/any/every + other + 单数/不可数 没有/任何/每个其他的…… other 加单数或不可数时，前面必须有修饰词
考点四 some ... others ... 一些……其他的……（泛指） 没有总范围，还可以有第三批、第四批
考点五 the others 剩余的全部（特指） 有总范围，除去一部分后剩下的全部
考点六 one ... the other ... 一个……另一个……（两者） 总范围固定为2，one 指一个，the other 指剩下的那个
考点七 another + 名词 再一个/另一个 在原先基础上再多一个/一组，原先有几个不重要

11. 泛指 vs 特指 对比总结

对比项 泛指（others） 特指（the others）
总范围 没有总范围 有总范围
含义 另外一些人/事/物（不限定全部） 剩余的全部人/事/物
类比 喜欢篮球的、喜欢足球的、喜欢乒乓球的……还可以有无数种 60人里20个女生 → 剩余40个"全部"是男生
关键词 some ... others ... the + 范围 + the others
✅ 泛指：Some people like tea. Others like coffee.（一些人喜欢茶，其他人喜欢咖啡。→ 还可以有喜欢果汁的、喜欢酒的……）
✅ 特指：In this room, some people like tea. The others like coffee.（这个房间里，一些人喜欢茶，其余的全部喜欢咖啡。→ 没有第三批了）

🎓 学习建议总结

  1. 牢记核心等式：other + 可数名词复数 = others。这是理解整个 other 系列的基石。
  2. 判断三步走：看到 other → 看后面有没有名词 → 没有就选 others；看到 others → 看后面有没有名词 → 有名词就是错的。
  3. 泛指 vs 特指：没有总范围用 others（some... others...），有总范围用 the others（剩余的全部）。
  4. 两者用 the other：总数=2 时，"一个……另一个……"用 one... the other...
  5. another = 再来一个：原先有几个不重要，在原先基础上"再来一个/一组"就用 another。another 后面的单位可以是时间、金额等任意量。
  6. 单数/不可数需要修饰词：other 加可数名词单数或不可数名词时，前面必须有 no/any/every 等词。
  7. 循序渐进：按照学习路线图一步步走，在课文中观察 other 系列的用法，保证不走弯路。听懂了可以再回去看原视频（"other全家桶"），会发现其实讲得很清楚，只是语速快而已。
