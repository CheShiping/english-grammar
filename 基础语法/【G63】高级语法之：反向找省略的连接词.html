【G63】高级语法之：反向找省略的连接词

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G63 是「基础语法」系列第63课，由陈老师主讲。本节课是句子部分的高级方法论课（续），紧接 G62「从属连词的省略」，专门讲解一种高级的逆向思维方法——反向找省略的连接词。

在 G62 中，老师正面讲解了引导词省略的三种常见情况（宾从第一个that / 定从中做宾语的关系代词 / 先行词the way的定从），并揭示了省略的本质原因——"不要引导词已经很清晰了"。本节课从反向角度切入：当你看到一个句子，找不到连接词，但根据谓语个数又知道应该有一个连接词时，如何用"反向找"的方法精确定位省略的连接词位置。

本节课的核心目标：掌握"反向找省略的连接词"的逆向思维方法——找到从句的谓语和主语，主语前面的位置就是省略的连接词所在之处。
前置知识要求：
本节课建立在 G40「五大基本句型」、G43「从句/复合句1.0」、G61「连接词个数≠V-1」、G62「从属连词的省略」的基础上。需要熟练掌握谓语动词识别、宾语从句、定语从句、引导词省略等知识。

2. 核心方法论：引导词在从句中的两种角色

老师首先回顾了引导词的基本知识，然后引出反向找连接词的理论基础：

从句的第一个词 = 引导词
→ 引导词的第一个作用：引导从句（放在从句句首）
→ 引导词的第二个作用：在从句中做成分（要么做主语，要么不做主语）

引导词做主语 vs 不做主语

情况 引导词角色 后面接什么 例句
情况一 引导词做主语 后面接谓语 I don't know who did it.（who = 主语，did = 谓语）
情况二 引导词不做主语 后面接主语 I don't know how he did it.（how = 状语，he = 主语）
核心逻辑：
- 引导词做了主语 → 后面接谓语（who did it）
- 引导词没做主语 → 后面接主语（he did it，he 是主语）
- 这是反向找连接词的理论基石：找到谓语 → 再找到主语 → 主语前面就是引导词

3. 核心方法论：反向找连接词的操作步骤

老师正式引入"反向找连接词"的方法，这是一种逆向思维，与正面找连接词的方法互补：

反向找连接词四步法

第一步：找到两个谓语动词 V1 和 V2
↓
第二步：确认缺少连接词（V-1=1，但句中没有连接词）
↓
第三步：找到 V2 和它的主语 S2
↓
第四步：S2 前面的位置 = 省略的连接词所在之处
核心口诀：
- 找到谓语 → 找到主语 → 主语前面就是引导词
- 从句句首的引导词不能省略（因为句首必须标识从句的开端）
- 所以省略的连接词一定不在句首，而在主语前面
- 反向找的时候，一定要找"V + S"的结构（V2前面找S2，S2前面就是省略的连接词）

4. 例句一：I think he is right.

分析过程（正向 + 反向结合）：
→ 找谓语：think（V1）+ is（V2）→ 两个谓语 → 需要 2-1=1 个连接词
→ 正向找：找不到连接词（句中没有 that/which/who 等词）
→ 反向找：找到 V2=is → 找到 S2=he → he 前面的位置 = 省略的连接词
→ 还原：I think (that) he is right.
→ 从句类型：I think 后面缺宾语 → 宾语从句 → 第一个 that 可省略 ✓

反向找的逻辑验证

→ 句首的引导词不能省略（句首必须标识从句开端）
→ 所以省略的连接词一定不在句首（即不在 he 前面更前面的位置）
→ 只能在 he 前面 → I think [___ he is right] → ___ = that
核心辨析——为什么是宾从而不是定从：
- I think 后面缺宾语（think 是及物动词）→ 后面是宾语从句
- 如果是定从，主句 I think 应该是完整的（不缺主语/宾语/表语）
- think 是及物动词，后面必须接东西 → 缺宾语 → 宾从

翻译结果

翻译：我认为他是正确的。

5. 例句二：This is the park we visited last weekend.

分析过程（正向 + 反向结合）：
→ 找谓语：is（V1）+ visited（V2）→ 两个谓语 → 需要 2-1=1 个连接词
→ 正向找：找不到连接词（句中没有 that/which/where 等词）
→ 反向找：找到 V2=visited → 找到 S2=we → we 前面的位置 = 省略的连接词
→ 还原：This is the park (that/which) we visited last weekend.

从句类型判断

→ 主句：This is the park（主系表，完整 ✓）→ 不是宾从
→ 从句：we visited last weekend（缺宾语 → visited 是及物动词）
→ 先行词：the park（指物）→ 关系代词用 that/which（不做主语，做宾语）
→ 定从中做宾语的关系代词 → 可省略 ✓
核心辨析——为什么是 that/which 而不是 where：
- we visited 中 visited 是及物动词，后面缺宾语
- 关系代词在从句中做 visited 的宾语 → 用 that/which
- 如果用 where（= in which），从句应该是 we were 或 we stayed（不缺宾语）
- 判断方法：把关系代词还原进去 → we visited ___（缺宾语）→ 用 that/which

翻译结果

翻译：这是我们上周末参观过的公园。

6. 正向找 vs 反向找 对照总结

方法 操作方式 适用场景 优点
正向找 根据省略的三种情况（宾从第一个that / 定从宾语关系代词 / the way），直接判断引导词是否可省略 熟悉省略规则，一眼能看出省略 直接、快速
反向找 找到V2和S2，S2前面的位置就是省略的连接词 找不到连接词，但知道应该有连接词 万能、不遗漏
核心逻辑：正向找和反向找结合使用，保证万无一失。正向找适合快速判断，反向找适合验证和发现遗漏。

9. 核心判断逻辑总结

G63 核心方法总结

第一步：找谓语动词 → 数个数 → 找连接词
↓
第二步：如果找不到连接词，但 V-1 > 0 → 需要连接词 → 用反向找
↓
第三步：找到 V2（第二个谓语）→ 找到 S2（V2的主语）
↓
第四步：S2 前面的位置 = 省略的连接词所在之处
↓
第五步：判断从句类型（宾从/定从）→ 确认省略是否合法
↓
第六步：正向找 + 反向找结合 → 万无一失
核心口诀：
- 找到谓语 → 找到主语 → 主语前面就是引导词
- 从句句首的引导词不能省略（句首必须标识从句开端）
