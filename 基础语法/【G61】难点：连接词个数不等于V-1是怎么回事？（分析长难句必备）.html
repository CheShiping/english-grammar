【G61】难点：连接词个数不等于V-1是怎么回事？（分析长难句必备）

来源：陈老师基础语法系列 | 整理与注释版

1. 课程背景与引入

G61 是「基础语法」系列第61课，由陈老师主讲。本节课是句子部分的方法论专题课，紧接 G60「长难句3」，专门解决一个核心问题——为什么连接词的个数有时会不等于 V-1？

在前面的课程中，老师反复强调一个公式：连接词个数 = V - 1（谓语动词个数减1）。这个公式在大多数情况下非常完美、非常舒服。但随着句子越来越长、越来越复杂，同学们会发现这个公式"失灵"了——连接词的个数竟然不等于 V-1！本节课就是要解释这种现象的四种原因。

本节课的核心目标：理解连接词个数 ≠ V-1 的四种原因（第二层并列、找错谓语、找错连接词、省略），掌握每种原因的识别方法和应对策略。
前置知识要求：
本节课建立在 G40「五大基本句型」、G43「从句/复合句1.0」、G51「省略」、G60「长难句3」的基础上。需要熟练掌握谓语动词识别、从属连词、AABB型动词、非谓语动词等知识。

2. 核心问题：连接词个数 ≠ V-1 是怎么回事？

老师首先回顾了基础公式，然后引出本节课的核心问题：

公式 含义 适用范围
连接词个数 = V - 1 从属连词的个数 = 谓语动词个数 - 1 大多数情况完美适用
连接词个数 ≠ V - 1 公式"失灵"了 句子越复杂越容易出现，共四种原因
核心口诀：
- 连接词个数 = V - 1 是基础公式，大多数情况适用
- 但句子越复杂，犯错的可能性越大
- 连接词个数 ≠ V-1 时，不要慌，检查四种原因

3. 原因一：第二层（从句之间的并列关系）

老师以第一个原因切入，解释了当从句太多时，从句和从句之间会形成并列关系，从而产生"第二层"的连接词：

I think that you are a pig and (that) you are ugly.
→ 谓语动词：think（谓语1）、are（谓语2）、are（谓语3）→ 共3个谓语
→ 按公式应该有 3-1=2 个连接词
→ 实际连接词：that（第1个）、and（第2个）、that（第3个）→ 共3个连接词！
→ and 就是"第二层"产生的连接词 → 连接词个数（3）≠ V-1（2）

第二层的产生机制

层次 说明 连接词
第一层 主句 + 直接从句（连接词 = V - 1） 第1个 that（引导宾语从句）
第二层 从句和从句之间形成并列关系 and（连接两个并列的 that 从句）
核心辨析——第二层连接词 vs 第一层连接词：
- 第一层：主句和从句之间的连接词（= V-1）
- 第二层：从句和从句之间并列产生的连接词（如 and、or）
- 第二层连接词不计入 V-1 的公式
- 类比：G59 中 whether...or whether... 的 all 也是第二层产生的

4. 原因二：找错谓语（AABB型动词）

老师以第二个原因切入，解释了 AABB型动词（过去式和过去分词同形）导致的"多找谓语"问题：

The report made by Mr. Chen...
→ made 是 make 的过去式和过去分词（AABB型：make-made-made）
→ made 既可以抽象成 did（谓语）→ 也可以抽象成 done（非谓语）
→ made by Mr. Chen → 被动 → done → 非谓语 → 后置定语
→ 如果把 made 误判为谓语 → 多找了一个谓语 → V 变大 → 公式失灵

AABB型动词的50%判断法

判断方法 操作 本句应用
主动/被动判断 看名词和动词的主动/被动关系 the report 和 make → 被动 → done → 非谓语 ✓
一山不容二虎 看主语后面有没有谓语了 主语后面有真正的谓语 → made 不能再做谓语 ✓
by标志 看后面有没有 by made by Mr. Chen → by 是被动标志 ✓
核心口诀：
- is + 过去分词 → 100% 被动语态（谓语）
- made/built 等 AABB型动词 → 只有50%是谓语，需要进一步判断
- 把非谓语当谓语 → 多找谓语 → V 变大 → 连接词个数 ≠ V-1
- 判断方法：主动/被动 + 一山不容二虎 + by标志

5. 原因三：找错连接词（that 的多重身份）

老师以第三个原因切入，解释了有些词长得像连接词，但实际上不是连接词的情况：

That man is a pig.
→ 只有一个谓语动词：is → V-1 = 1-1 = 0 → 应该没有连接词
→ 但句首有 That → 很多同学一看到 that 就很兴奋，把它当成连接词 → 错了！
→ That man → that 是指示代词（"那个"）→ 修饰 man → 不是连接词 ✓

that 的多重身份速查表

身份 词性 判断方法 例句
从属连词（引导词） 连词，不做成分 that 后跟完整句子（主+谓） I think that you are a pig.
关系代词 代词，在从句中做成分 that 后跟主谓结构，且 that 在从句中做主/宾 The book that I bought...
指示代词（那个） 代词/限定词 that 后跟名词短语（无主谓结构） That man is a pig.
核心口诀：
- 看到 that 不要激动 → 先看后面跟什么
- that + 主谓结构 → 引导词/关系代词
- that + 名词短语 → 指示代词（"那个"），不是连接词
- 把非连接词当成连接词 → 多找了连接词 → 连接词个数 ≠ V-1

6. 原因四：省略（预告）

老师提到第四个原因——省略，但决定不在本节课详细展开，而是留到下节课专门讲解：

省略导致连接词个数 ≠ V-1 的机制：

省略 → 某些从句中的引导词被省略了 → 看起来连接词少了 → 连接词个数 ≠ V-1
→ 但实际连接词并没有少，只是被省略了
→ 下节课详细讲解
核心提示：
- 省略是连接词个数 ≠ V-1 的第四种原因
- 省略的引导词（如 that）在语法上仍然存在，只是口语/非正式文体中被省略了
- 下节课会专门讲解省略的机制和应对方法

8. 核心知识点总结

知识点一：第二层并列

判断维度 说明
产生条件 从句太多，从句和从句之间形成并列关系
典型连接词 and / or（连接两个并列的从句）
是否计入 V-1 不计入（第二层连接词独立于 V-1 公式）
典型例句 I think that you are a pig and (that) you are ugly.

知识点二：AABB型动词的50%判断法

判断维度 说明
什么是AABB型 过去式和过去分词同形的动词（make-made-made / build-built-built）
50%含义 made/built 既可以抽象成 did（谓语）→ 也可以抽象成 done（非谓语）
误判后果 把非谓语当谓语 → 多找V → V 变大 → 连接词个数 ≠ V-1
判断方法 ① 主动/被动判断 ② 一山不容二虎 ③ by标志

知识点三：that 的多重身份

判断维度 说明
从属连词 that + 完整句子（主+谓）→ 引导词，不做成分
关系代词 that + 主谓结构 + that 做成分 → 关系代词
指示代词 that + 名词短语（无主谓）→ "那个"，不是连接词
误判后果 把指示代词 that 当成连接词 → 多找连接词 → 连接词个数 ≠ V-1

知识点四：省略（预告）

判断维度 说明
机制 引导词被省略 → 看起来连接词少了 → 连接词个数 ≠ V-1
本质 连接词并没有真正消失，只是在口语/非正式文体中被省略了

10. 核心判断逻辑总结

G61 核心方法总结

第一步：发现连接词个数 ≠ V-1 → 不要慌
↓
第二步：检查原因一 → 有没有第二层并列（and/or 连接两个从句）
↓
第三步：检查原因二 → 有没有AABB型动词被误判为谓语（made/built + by）
↓
第四步：检查原因三 → 有没有 that 是指示代词（that + 名词短语）
↓
第五步：检查原因四 → 有没有引导词被省略（下节课详讲）
↓
第六步：排除所有异常后 → 回到正常分析流程
核心口诀：
- 连接词个数 ≠ V-1 时，不要慌，检查四种原因
- 原因一：第二层并列 → and/or 连接两个从句 → 不计入 V-1
- 原因二：找错谓语 → AABB型动词（made/built）→ 用三种方法判断
- 原因三：找错连接词 → that + 名词短语 → 指示代词不是连接词
- 原因四：省略 → 引导词被省略了 → 下节课详讲
- 句子越复杂，犯错的可能性越大 → 逐项排查
