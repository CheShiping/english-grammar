1. 课程背景与引入

G71 是「基础语法」系列的收官课（最后一课），由陈老师主讲。本节课是实战操作课，紧接 G70「一张图归纳所有英语句子」，将 G70 提出的万能公式——简单陈述句模型——实际应用到50个句子的逐句分析中，演示如何一步步拆解各种句型。

本节课重点讲解：① 万能公式的实际操作步骤（从开头到谓语到复杂化）、② 句子开头的三种可能性（状语/主语/助动词倒装）、③ it 的两种身份辨析（人称代词 vs 形式主语）、④ 谓语部分的三种构成方式（助动词+实系动词/实系动词单独/系动词单独）、⑤ 五大基本句型在50个句子中的具体体现、⑥ 句子复杂化的三种方法（从句/并列/分裂）。

本节课的核心目标：通过50个句子的纵向分析，熟练掌握万能公式的实际操作流程——从判断开头（状语/主语/倒装）→ 找主语（六种形式）→ 判断主谓之间的障碍物 → 找谓语（三种构成）→ 判断句型 → 分析复杂化方式。
前置知识要求：
本节课是前面70节课的总和，需要熟练掌握简单陈述句万能模型、主语六种形式、谓语三种构成、五大基本句型、句子复杂化三方法、模型的三种例外等知识。

2. 万能公式的实际操作步骤

老师以一个万能公式为纲，逐一分析50个句子，演示具体的操作流程：

(状语) + S + (后置定语/状语/同位语/插入语) + V + ...

第一步：判断句子开头

句子开头不一定是主语，有三种可能性：

开头类型 说明 典型标志 例句
状语开头 时间/地点/方式等状语放在句首 Yesterday / In the morning / When I was young... Yesterday, they eat...
主语开头 主语直接放在句首（最常见） 名词短语/代词/不定式/动名词/从句 You to swim... / I play...
助动词开头（倒装） 疑问句/倒装句，助动词提前 Do/Does/Did/Is/Are/Was/Were/Can... 开头 Would you be...? / Do you remember...?
核心口诀：
- 看到句子不要慌，先看开头是什么
- 状语开头 → 跳过状语找主语
- 主语开头 → 正常分析
- 助动词开头 → 倒装句，要"调回去"（把助动词放回主语后面）

3. 主语的六种形式（实战识别）

老师通过50个句子中的主语，逐一演示六种主语形式的识别方法：

第一类：名词性成分（前面可加后置定语）

主语形式 说明 例句中的主语
名词短语 普通名词+定语 the Chinese / a man / the scientist / some new computers / the bikes / a car / Comrade Li
DTS（代词/限定词/数词） 人称代词 you / he / I / we / they / her mother / Lily
Shots（缩略形式） 名词性缩略形式 （部分缩略名词短语）

第二类：长形式（可能头重脚轻，用it做形式主语）

主语形式 说明 例句中的主语
不定式 (to do) to + 动词原形 to swim（做主语）
动名词 (doing) 动词+ing （部分doing形式做主语）
从句 (引导词+句子) that/what/whether + 完整句子 It was a pity that... / It takes you three hours to go to Hong Kong... / It is hope that... / What we are most interested in...
核心辨析——it的两种身份：
- it做人称代词：it 后面不接 to do / doing / that 从句 → it 就是主语本身（如 It is sunny）
- it做形式主语：it 后面接 to do / doing / that 从句 → it 代替后面太长的真正主语
- 判断方法：看到 it 开头 + 后面有 to do / doing / that 从句 → 形式主语

4. 谓语部分的三种构成方式（实战识别）

老师通过分析50个句子中的谓语，演示三种构成方式的识别：

谓语构成 说明 能否单独构成谓语 例句中的谓语
助动词 + 实系动词 助动词（be/情态/do/完成）+ 动词原形/doing/done 不能单独构成，必须加实系动词 should put / don't believe / should do / had better / are hoping for / has just got / would be / is reporting / I'm writing / do remember
实系动词单独构成 及物动词/不及物动词单独做谓语 可以单独构成谓语 goes out / set / takes / spent / is interested in / spoke / stood up / remember / think / solve / put
系动词单独构成 be动词/感官动词/状态动词单独做谓语 可以单独构成谓语 is / was / are / keep / was a pity / was the words
核心口诀——助动词的四类及后接形式：
- be动词（am/is/are/was/were）→ 后接 doing 或 done
- 情态动词（can/could/would/may/might...）→ 后接动词原形
- 狭义助动词（do/does/did）→ 后接动词原形
- 完成助动词（have/has/had）→ 后接过去分词（done）

5. 主谓之间的"障碍物"识别

老师强调，主谓之间不一定直接跟着谓语，可能隔着各种"障碍物"，按概率从高到低排列：

障碍物类型 概率 说明 例句
谓语（助动词） 最高 助动词放在主语和实系动词之间 should put / often goes / just got
后置定语 高 名词后面的修饰性短语 the scientist in the lab / the Chinese who...
状语 中 状语可以放在助动词和实系动词之间 just got / often goes
同位语 低 名词后面的解释性成分 the news that China successfully launched...
插入语 最低 可插入句子的任何位置 the news, I think, is...
核心口诀：
- 看到句子不要慌，按概率依次判断主谓之间是什么
- 概率排序：谓语（助动词）> 后置定语 > 状语 > 同位语 > 插入语
- 状语是最强大的，到处都可以放（助动词和实系动词之间）

6. 五大基本句型在50个句子中的体现

老师通过分析50个句子，逐一演示五大基本句型的具体体现：

句型一：SV（主谓）

He set.
→ He = 主语；set = 不及物动词（sv）→ SV结构
→ 后面可加状语：He set in the classroom.

句型二：SVO（主谓宾）

You put your things.
→ You = 主语；put = 及物动词（vt1）；your things = 宾语 → SVO结构
→ 宾语后面可加定语/状语/同位语
Scientists made a report.
→ Scientists = 主语；made = 及物动词；a report = 宾语 → SVO结构
→ report 是名词短语，后面可加定语从句

句型三：SVOC（主谓宾宾补）

We solve the students playing basketball.
→ We = 主语；solve = 及物动词；the students = 宾语；playing basketball = 宾补 → SVOC结构
→ 宾补后面可加定语/状语
I don't believe that story true.
→ I = 主语；don't believe = 谓语；that story = 宾语；true = 宾补 → SVOC结构

句型四：SVIO DO（主谓间宾直宾）

He took me a deal.
→ He = 主语；took = 双宾语动词；me = 间宾（IO）；a deal = 直宾（DO）→ SVIO DO结构
→ 可变序：He took a deal to me.
She made us a report.
→ She = 主语；made = 双宾语动词；us = 间宾；a report = 直宾 → SVIO DO结构
→ a report 是名词短语，后面可加定语从句

句型五：SVT（主系表）

It was a pity.
→ It = 主语（形式主语）；was = 系动词；a pity = 表语 → SVT结构
Your things are a great pleasure.
→ Your things = 主语；are = 系动词；a great pleasure = 表语 → SVT结构
Lily is interested in English.
→ Lily = 主语；is interested in = 系动词短语；English = 宾语 → SVT结构（简单分析：be interested in 整体看作谓语+宾语）
核心辨析——be interested in 的两种分析思路：
- 精细分析：is = 系动词；interested = 表语；in English = 状语
- 简单分析：be interested in 整体看作谓语动词短语 + English（宾语）
- 老师建议：最简单的分析方法，把 be interested in 整体当作一个实意动词

7. 句子复杂化的三种方法（实战体现）

老师通过分析50个句子，演示句子复杂化的三种方法：

方法一：从句（用一个句子充当某个成分）

主语从句：
→ It was a pity that...（it 做形式主语，that 引导主语从句）
→ It takes you three hours to go to Hong Kong by air（it 做形式主语，不定式做真正主语）
→ What we are most interested in...（what 引导主语从句做主语）
→ That she will go...（that 引导主语从句做主语）
宾语从句：
→ I don't believe that the story is true.（that 引导宾语从句做 believe 的宾语）
→ Do you remember that...?（that 引导宾语从句）
同位语从句：
→ the news that China successfully launched a new experimental communications satellite.（that 引导同位语从句，等同于 news）

方法二：并列（用and连接相同结构）

并列谓语：
→ stood up and spoke（两个不及物动词用 and 连接，共享主语）
→ 并列可以让句子无限延伸

方法三：分裂（环环相扣，每个成分可以再分）

名词分裂出定语从句：
→ a report for us（名词 report 后面加介词短语做后置定语）
→ 名词短语很笼统 → 后面加定语/状语/同位语 → 无限延伸
不定式分裂出状语：
→ to swim in the river（不定式 to swim 保留了动词属性 → 后面可加状语）
→ 地点状语 in the river 修饰 swim
宾语分裂出宾补和状语：
→ the students playing basketball on the playground happily
→ 宾语 the students → 宾补 playing basketball → 状语 on the playground（地点）+ happily（程度）
核心口诀：
- 从句 = 用一个句子充当某个成分（主语从句/宾语从句/同位语从句）
- 并列 = 用 and 连接相同结构（谓语and谓语/句子and句子）
- 分裂 = 环环相扣，名词→定语从句，不定式→分裂出状语，宾语→宾补+状语
- 所有复杂句 = 简单句 + 从句/并列/分裂

8. 模型的三种例外（实战识别）

老师通过分析50个句子，演示三种例外的识别方法：

例外一：祈使句（省略主语和助动词）

Keep...
→ 动词原形开头 → 省略了主语（you）和助动词 → 祈使句
→ 本质上是省略，仍然满足模型，但看起来不满足

例外二：倒装句（谓语跑到主语前面）

Would you be...?
→ 助动词 would 开头 → 疑问句 → 倒装句
→ 要"调回去"：you would be... → 恢复正常语序再分析
Do you remember...?
→ 助动词 do 开头 → 疑问句 → 倒装句
→ 调回去：you remember... → 主语 you + 谓语 remember

例外三：强调句（It is/was...that...）

→ 50个句子中没有出现强调句（老师提到强调句在 G69 专门讲过）
→ 强调句 = 在完整简单句基础上加了 It is/was...that...
核心辨析——祈使句 vs 不定式做主语：
- 祈使句：动词原形开头，省略主语 → Keep... / Put... / Do...
- 不定式做主语：to + 动词原形开头 → to swim...
- 判断方法：看开头有没有 to → 有 to → 不定式做主语；没有 to，动词原形开头 → 祈使句（省略主语）

10. 核心知识点总结

知识点一：万能公式操作流程

步骤 操作 注意事项
第一步 判断句子开头 状语开头→跳过；主语开头→正常；助动词开头→倒装，调回去
第二步 找主语（六种形式） 名词短语/DTS/Shots/to do/doing/从句；it注意区分人称代词和形式主语
第三步 判断主谓之间的障碍物 概率排序：助动词>后置定语>状语>同位语>插入语
第四步 找谓语（三种构成） 助动词+实系动词/实系动词单独/系动词单独
第五步 判断句型 SV/SVO/SVOC/SVitOC/SVIO DO/SVT
第六步 分析复杂化方式 从句/并列/分裂
第七步 检查例外 祈使句/倒装句/强调句

知识点二：it的两种身份辨析

身份 判断方法 例句
人称代词（主语本身） it 后面不接 to do / doing / that 从句 It is sunny. / It is a pity.
形式主语 it 后面接 to do / doing / that 从句 It was a pity that... / It takes you three hours to go...

知识点三：谓语构成的实战识别

谓语构成 识别标志 典型例句
助动词+实系动词 should/does/did/is/are/was/were/can/would/have + 动词原形/doing/done should put / don't believe / are hoping for / has just got / would be / is reporting
实系动词单独构成 及物动词/不及物动词单独做谓语 goes out / set / takes / spent / spoke / remember / think / solve / put
系动词单独构成 be动词/感官动词/状态动词单独做谓语 is / was / are / keep

知识点四：祈使句 vs 不定式做主语的辨析

对比维度 祈使句 不定式做主语
开头标志 动词原形开头（无 to） to + 动词原形
主语 省略了 you 不定式本身就是主语
例句 Keep... / Put... / Do... To swim is good.

知识点五：句子复杂化的三种方法（实战总结）

方法 核心逻辑 50个句子中的体现
从句 用一个句子充当某个成分 主语从句（It was a pity that...）/ 宾语从句（I don't believe that...）/ 同位语从句（the news that...）
并列 用and连接相同结构 stood up and spoke（并列谓语）

- it 注意区分：人称代词 vs 形式主语（看后面有没有 to do/doing/that）
- 主谓之间障碍物：助动词>后置定语>状语>同位语>插入语
- 谓语三种构成：助动词+实系动词/实系动词单独/系动词单独
- 助动词四类：be→doing/done；情态→原形；do→原形；have→done
- 五大句型：SV/SVO/SVOC/SVitOC/SVIO DO/SVT
- 复杂化三方法：从句/并列/分裂
- 三种例外：祈使句/倒装句/强调句
- 祈使句 vs 不定式：有 to→不定式做主语；无 to→祈使句（省略主语）

🎓 学习建议总结

  1. 牢记万能公式操作流程：开头→主语→障碍物→谓语→句型→复杂化→例外。这是本节课最重要的方法论，掌握了这个流程就能分析任何英语句子。
  2. 牢记主语的六种形式和 it 的两种身份：名词短语/DTS/Shots/to do/doing/从句。it 后面接 to do/doing/that → 形式主语；不接 → 人称代词。
  3. 牢记主谓之间障碍物的概率排序：助动词 > 后置定语 > 状语 > 同位语 > 插入语。看到句子不要慌，按概率依次判断。
  4. 牢记谓语的三种构成：助动词+实系动词（不能单独）/ 实系动词单独 / 系动词单独。谓语结尾一定落脚到实系动词或系动词。
  5. 牢记祈使句 vs 不定式做主语：有 to → 不定式做主语；无 to，动词原形开头 → 祈使句（省略主语）。
  6. 牢记倒装句要"调回去"：助动词开头 → 把助动词放回主语后面 → 恢复正常语序再分析。
  7. 牢记复杂化三方法：从句（用一个句子充当成分）/ 并列（用and连接相同结构）/ 分裂（环环相扣）。所有复杂句 = 简单句 + 从句/并列/分裂。
  8. 综合应用建议：拿到任何长难句，先用万能公式定位开头→主语→障碍物→谓语→句型→复杂化，层层拆解，万无一失。这是基础语法的收官课，标志着基础语法体系的完成。
